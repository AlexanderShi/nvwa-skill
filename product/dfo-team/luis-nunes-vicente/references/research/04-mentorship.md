## 3. Observable mentoring patterns (practice, inferred from records)

1. **Thesis = one framework + its theory + its numerics + one real application.** Diouane (ES theory + 3D full-waveform inversion); Royer (complexity + "numerical relevance", Airbus/IRT jury member); Liu (SMG theory + fairness applications). Custódio (simplex derivatives + SID-PSM software). Pattern holds in 4/4 verified theses.
2. **Co-supervision across institutions** (Coimbra ↔ Toulouse with Gratton) for 2 of the 4 verified theses. The student gets both a theoretical DFO advisor and an applications-rich numerical-analysis environment (CERFACS/ENSEEIHT context is inference).
3. **Students become long-term lineage holders of the line they started.** Custódio → co-author of DMS 2011 and of the 2012 discontinuous analysis (later follow-ups not verified); Royer → probabilistic direct search (2015, 2018, 2019); Diouane → ES + merit function follow-ups ("A merit function approach for evolution strategies", ResearchGate listing, authors not confirmed ⚠️).
4. **Lehigh era: student/postdoc first author, code in the student's own GitHub.** MOO_Fairness (Liu), BSG_Methods_Con_Unc (Kent), snee (Giovannelli). Inference: the student owns the implementation, and the code is public at submission.
5. **Title conventions show the advisor's standard**: "Complexity Analysis and Numerical Relevance" (Royer) and "Globally convergent … with application to …" (Diouane) both pair a theoretical guarantee with practical relevance, echoing S1 in 02 ("theory and algorithms, software development, and industrial applications").
