- **D1 Problem & entry**: The entry is an engineering variable type. Categorical variables (material, shape, color) take values from a list, their numeric codes are meaningless, and the simulator rejects any other value, so their discreteness must hold at every iterate and not only at the solution (p. 14). The standard alternative, parametric studies over the categorical values, becomes too costly when there are many categorical variables with several values each (p. 15). Two further pathologies are added (pp. 15–16):
  - functions may be discontinuous, undefined, or fail to return a value at all (citing Booker et al., p. 15);
  - a change in a discrete variable can change the constraints and the problem dimension. In the thermal-insulation case, the number of intercepts sets the number of continuous variables and of insulator choices (p. 16). This is handled by using maximum dimensions, ignoring unused variables and setting unused constraints to the zero function (p. 16).

  The formal problem (1.1) is min f(x) s.t. C(x) ≤ 0 over X = X^c × X^d, with f and C extended-valued, and X^c(x^d) given by linear constraints that depend on x^d (pp. 16–17). No continuity or smoothness is assumed; the strength of each result depends on such properties (p. 15; abstract p. 3). The gap is argued family by family. MINLP methods need an integrality relaxation (impossible for categorical variables), convexity and derivatives (pp. 24–25). Heuristics lack convergence theory and cost many evaluations (pp. 34–35, 41–42). GPS already existed for bound-constrained MVP [8] and for nonlinearly constrained NLP [7], but not for both at once (pp. 20, 42).
  - Transferable technique: define the problem class by the operational property that defeats existing methods (here: categorical values cannot be relaxed because the simulator rejects them). Then show which method families that property rules out before you propose your own.
- **D2 Core idea & algorithm design**: One algorithm class, FMGPS, merges filter GPS [7] and MGPS [8]. It reduces to [8] when there are no nonlinear constraints and to [7] when there are no categorical variables (pp. 97, 116, 168). Filter GPS itself reduces to basic GPS when h ≡ 0 (p. 69). Five design moves:
  - *Mesh.* The mesh is the direct product of X^d with a union of lattices, one generating matrix G_i per discrete combination. This is more general than [8], which used a single matrix (pp. 75–76). The mesh is conceptual and never built (p. 76). Each lattice is translated from the current iterate, not from a neighbor, for the sake of convergence (p. 78).
  - *Categorical neighborhoods.* The user supplies a set-valued map N(x): finite, containing x, and continuous in the sense of Definition 5.2 (pp. 76–77). Local optimality is defined relative to N, over balls around every discrete neighbor (Def. 5.3, p. 77). Neighbors must lie on the current mesh (A4, pp. 78, 82). For categorical variables, special knowledge of the engineering process may be the only guide to N (p. 76).
  - *Extended poll.* When the poll and the discrete neighbors fail, continuous polling continues around every neighbor whose value lies within a trigger ξ_k of the incumbent (p. 79). A practical rule is ξ_k = max{ξ, 0.05|f(x_k)|}. A higher trigger gives a more global solution at more evaluations, a lower one a more local solution (p. 79).
  - *Filter bookkeeping.* Dominance is on (f, h) with h = ‖C⁺‖. The squared 2-norm lets h inherit the smoothness of C (p. 66), and the filter avoids a user-weighted merit function (p. 66). Two modifications of Fletcher–Leyffer: a cap h_max on the violation, and a filter holding only infeasible points while the best feasible point is tracked separately, which avoids blocking entries (p. 67). There are two poll centers, the best feasible and the least infeasible point (p. 68). Polling around any other filter point is allowed but counts as part of the Search, so the theory is preserved (p. 68).
  - *FMGPS specifics.* Two triggers, ξ^f on the feasible side and ξ^h on the infeasible side, define when a discrete neighbor is almost a new incumbent (pp. 99–100; Fig. 6.1, p. 101). Each extended poll runs its own temporary local filter, which is merged into the main filter and then discarded (p. 102; Fig. 6.2, p. 103). The author says there are several workable choices here and that this one was chosen because it generalizes Ch. 5 (p. 99).
  - *Unchanged parts.* Acceptance by simple decrease (or by finding an unfiltered point), rational τ and the coarsen/refine rules (4.5)–(4.6) (pp. 59, 104), and the Search as any finite strategy on the mesh (pp. 58, 104). Linear constraints are handled by not evaluating points outside X, which is equivalent to the barrier f + indicator of [6–8] (pp. 56–57), with conforming directions from the Lewis–Torczon construction (Fig. 4.3, p. 62).
  - *Ch. 8 move.* Available derivatives are used only to prune ascent directions from the poll, never to take gradient steps (Def. 8.1, p. 144). The reason given: gradient methods converge quickly to local minima, and direct search is chosen in the hope of a better one (p. 143). Positive bases give small polls without derivatives but prune poorly with them (p. 147), so the direction set is enlarged to D = {−1,0,1}^n, which prunes to one direction (Thm 8.8, pp. 152–153). If every pruned poll point lies outside X, no f-evaluation is needed at all (p. 145).
  - Transferable technique: when adding a feature (nonlinear constraints, categorical variables) to an algorithm, define every new acceptance or trigger rule so that it collapses to the old rule when the feature is absent. The old theorems then become corollaries, and only the new cases need proofs.
  - Transferable technique: to use cheap derivative information inside a direct search without giving up its search for better local minima, let the derivative only delete poll directions, and choose a richer direction set so that the deletion leaves as few directions as possible.
- **D3 Assumptions & model**:
  - *On the functions.* f and C take values in ℝ ∪ {∞} and are not assumed continuous (pp. 16, 56). Each result is tied to a local property at a limit point: lower semicontinuity, continuity, Lipschitz continuity, or differentiability plus D-regularity (the ladder summarized on pp. 95–96, 121–123).
  - *Algorithmic assumptions.* A1: iterates lie in a compact set, justified because most engineering problems have simple bounds (pp. 62–63). A2: D = GZ contains tangent-cone generators for every point, which holds if G = I and A is rational (p. 63). A3: the direction choice conforms to the boundary (p. 62). A4: neighbors lie on the mesh (p. 82). A2 and A3 hold automatically in the unconstrained case (p. 63). N must be continuous at the limit point to carry neighbors to the limit (Thm 5.12, pp. 87–88).
  - *Weakened smoothness.* Strict differentiability is replaced by three conditions: Lipschitz near the point, differentiable at it, and D-regular along the limit directions (Theorem 3.21, pp. 54–55). The three are equivalent to strict differentiability in the unconstrained case (Thm 3.19 and the remark on p. 53). The longer hypothesis list is kept on purpose, to show how the constrained and unconstrained cases relate (p. 54).
  - *Filter case.* To get results for f, trial points must be filtered by the poll center itself infinitely often (pp. 111–114). Remark 6.23 says this holds automatically if the best feasible point is chosen as poll center infinitely often, or if the limit is strictly feasible with C continuous there. The first condition is chiefly an algorithmic choice (p. 116).
  - *Equalities.* They are allowed in the theory but cause trouble in practice, because points outside X are never evaluated and roundoff removes feasible points. Variables should be eliminated until every constraint has ℓ < u (pp. 57, 75, 98).
  - *Application model.* Constant cross-section per insulator (p. 130); the load hangs from the system, so only tensile strength matters (p. 130); cycle-efficiency coefficients are piecewise constant in temperature (p. 133); tabulated data are fitted by cubic splines and integrated by a composite Simpson rule that is exact on cubics (p. 133).
  - Transferable technique: when a theorem needs an extra hypothesis, list the concrete algorithmic settings that make it hold automatically, as Remark 6.23 does (p. 116). The user can then obtain the guarantee through configuration rather than by hoping the problem is nice.
- **D4 Analysis & proof techniques**:
  - *Skeleton (Chs 5–6).* (i) Mesh size: a lower bound on the distance between mesh points in terms of ‖G_i⁻¹‖ (Lemma 5.7, p. 84) and an upper bound on Δ_k (Lemma 5.8, p. 85). Then lim inf Δ_k = 0 by Torczon's lattice argument: with rational τ = p/q, all iterates with the same discrete part lie on one translated integer lattice, so a compact set holds finitely many of them (Thm 5.9, pp. 85–86). (ii) A refining subsequence exists, with limits x̂, ŷ ∈ N(x̂) and ẑ, using the continuity of N (Thm 5.12, pp. 87–88). (iii) The key one-line bound: f°(x̂;(d,0)) ≥ lim sup of the failed-poll quotients (f(x_k+Δ_k(d,0)) − f(x_k))/Δ_k ≥ 0 for every limit direction d (Thm 5.14, p. 89; the same device for h, Thm 6.11, pp. 107–108). (iv) Lift to KKT through positive spanning plus D-regularity (Thm 3.21, pp. 54–55; Thm 5.16, pp. 90–91).
  - *Necessity examples used to fence the ladder.* The dense-mesh example from [6] shows D = GZ is needed (p. 86). The irrational-τ example in a revised [4] shows rational τ is essential (p. 87). ‖x‖_∞ from (1,1) with coordinate directions stalls although f° ≥ 0 on every d ∈ D, so the directional result cannot be strengthened (Example 4.7, pp. 64–65). Example 3.20 is D-regular but not regular because D does not positively span (p. 53). Example 8.7 refutes the natural conjecture that any direction closer in angle than d^(∞) prunes to a singleton (p. 152). The counterexample for ȳ in [8] motivates the strong extended poll (pp. 93, 115).
  - *Other devices.* A distance-sweep argument yields infinitely many limit points of extended-poll centers and J_k → ∞ (Thm 5.18, pp. 92–93). A contradiction through the strong extended poll (Thm 5.19, pp. 94–95). A non-stalling proof builds an unfiltered trial point between two filter entries (Thm 6.25, p. 117). The prune-to-singleton construction D(v) = {d̂} ∪ A(v) is proved in two cases (Thm 8.8, pp. 152–153). Cardinality bounds for positive bases come from pruning by both v and −v (Prop. 8.3, p. 148). Sign accuracy of the large components of an approximate gradient suffices for pruning (Def. 8.10–Thm 8.13, pp. 154–156).
  - *Proof style.* A direct proof replaces [8]'s proof by contradiction and is shorter (Thm 5.13, p. 88). Proofs of results identical to earlier ones are not repeated (p. 105).
  - *Limits stated in the analysis.* Under the filter, the result for f is that −∇f lies in the polar of the cone of limit directions, not KKT (Thms 4.20, 6.20; pp. 72, 114). Theorem 6.25 does not rule out stalling when p_k alternates between two kinds of unsuccessful iteration (pp. 117–118). No rates or complexity bounds are attempted.
  - Reader's note: in the second case of Theorem 8.18 (p. 161), the text says the right-hand side of (8.9) is bounded below by zero because dᵀ∇f(x_k) ≥ 0. For pruned directions, the quotient at step Δ_k is never evaluated and is not bounded by that sign condition. The conclusion f°(x̂;d) ≥ 0 still follows by choosing t_k ↓ 0 at each x_k inside the lim sup, a step the text does not write out.
  - Transferable technique: for any direct-search variant, get the first rung of the ladder from the single inequality f°(x̂;d) ≥ lim sup of the failed-poll difference quotients along a refining subsequence. Every higher rung is then a lemma about which directions d survive in the limit (conformity, positive spanning, D-regularity).
- **D5 Numerical experiments**:
  - *Application (Ch. 7).* The solver is NOMADm. Model parameters are in Table 7.1: T_H = 300 K, T_C = 4.2 K, L = 100 cm, n_max = 10, F = 250 kN, m_max = 10 kg, δ = 5% (p. 135). Settings: Δ_0 = 10; stop when Δ_k ≤ 0.15625; no coarsening; refinement by halving, because the 2^ℓ schedule of [89] could not be reproduced in NOMADm (pp. 135–137). Triggers are 1% for f (as in [89]) and 5% for h (p. 135). The initial design and the neighbor definition are those of [89], for comparability (pp. 133–135). The Search is a poll around the least infeasible point; the Poll is around the best feasible point (p. 135).
  - *Validation first.* The designs of Hilal–Boom and Hilal–Eyssa were reproduced. For stainless steel they match almost exactly; for epoxy the small differences are attributed to the integration method and to data density (4 against 18 tabulated temperatures) (pp. 135–136). A rerun of [89] converged to a different design, 25.589 against 25.294 W/cm, attributed to the refinement schedule (pp. 136–137, Table 7.2).
  - *Staged constraints.* First, the old designs were checked against the new constraints; thermal contraction was violated by about 8% (p. 137). Then the partial model (implicit stress constraint, variable areas) gave 24.551 W/cm, and the full model 23.768 W/cm, against 53.2 W/cm for Hilal–Eyssa (pp. 137–138, Table 7.3). The unexpected slight improvement after adding constraints is reported. It is explained by a different path to another local minimizer, with a note that the theory guarantees stationarity for the linearly constrained partial model but not for the full model (p. 139). Normalized power (P·L/A) is reported for comparability with the literature (pp. 136, 139).
  - *Plots.* Incumbent power against function evaluations, with more than 9000 evaluations in the run; the typical L shape is attributed to the difficulty of stopping rules (Fig. 7.2, pp. 139–140). Filter snapshots after 150, 200 and 500 evaluations (Fig. 7.3, pp. 139–141). Constraints are scaled by their right-hand sides, so h_max = 1 means 100% violation (pp. 140–141).
  - *CUTE (Ch. 8).* Eight poll strategies: standard 2n and n+1, their gradient-pruned versions, three pruned {−1,0,1}^n variants and one hybrid (p. 162). No Search. Stop at 10⁻⁴ accuracy or 50,000 evaluations, the reasonable limit of NOMADm (p. 162). Final f, the number of f-evaluations and the number of gradient evaluations are reported per problem (Table 8.1, pp. 166–167).
  - *Fairness rule.* When a run ended very quickly at an exact stationary point, it was repeated from a slightly perturbed starting point, so that no strategy would look gratuitously good (p. 163). Starting points were chosen where CUTE gives none, and an infeasible start was moved to the nearest bound (p. 164).
  - *Findings.* The pruned variants needed fewer evaluations but often ended at higher values (p. 164). No standard method used fewer evaluations than a 3n gradient method; there is one exception against its own pruned counterpart (MDHOLE, Standn+1) (p. 164). PALMER1 is discussed as a typical trade-off (pp. 164–165). Failures are shown: every strategy hits the 50,000 cap on PALMER1A, and Standn+1/Gradn+1 hit it on BARD and OSBORNEB (pp. 166–167). In Example 8.19, adding a two-point random search to Grad(∞)3n reaches the global minimizer (−750), where the pure poll variants stop at local ones (p. 163).
  - Not found: a seed for that random search; any solver from another family; profiles; CPU times.
  - Reader's note: the text announces seven poll strategies and lists eight (p. 162). It says 18 CUTE problems (pp. 161, 186), while Table 8.1 (pp. 166–167) and Appendix A both list 20.
  - Transferable technique: before optimizing with a new or extended model, reproduce the published designs with it and explain each discrepancy by a mechanism (integration rule, data density, refinement schedule). Then add constraints in stages, so that each change in the objective prices one group of constraints (pp. 135–139).
- **D6 Positioning**:
  - *Structure.* Chapter 2 is sorted by method family. Each family ends with a suitability paragraph that names the property of the target class it violates (pp. 24–25, 34–35, 41–42).
  - *Critique by mechanism.* MINLP needs relaxation, convexity and derivatives (pp. 24–25). Evolutionary algorithms have slow rates and a high evaluation cost (pp. 32, 34–35). The Lewis–Torczon augmented-Lagrangian GPS gives no penalty-update strategy and no numerical results (p. 37). The Coope–Price grid methods must assume that the mesh size goes to zero, which GPS proves (pp. 41, 58, 174). Hart's evolutionary pattern search proves only probabilistic analogs, which the thesis calls weaker than GPS results (pp. 41, 172). Bünner et al. use direct search as an unproven heuristic (p. 41).
  - *Heuristics reassigned, not rejected.* They belong in the Search step (p. 42), for example simulated annealing on a surrogate (pp. 174–175).
  - *Self-positioning.* The thesis generalizes Torczon, Lewis–Torczon and Audet–Dennis, whose algorithms become instances of FMGPS (p. 121). It claims the first algorithm with provable convergence for MVP with general nonlinear constraints (p. 168).
  - *Application.* Earlier thermal-insulation studies do not optimize over the categorical variables (pp. 126–127). The 65% power reduction of Kokkolaras–Audet–Dennis is the baseline being extended (p. 127).
  - *Audet's own report.* TR98-24 [4] (1998, p. 176) is cited for examples showing that Torczon's results cannot be relaxed (p. 36), for the irrational-τ example (p. 87), and for a pathological case where GPS starts at a global maximum and never moves (pp. 171–172).
  - Transferable technique: end each family in a related-work chapter with a suitability paragraph that names the property of your target problem the family violates. When the family is still useful, say where it goes inside your method (here, heuristics go into the Search step).

  - *Attribution at theorem level.* Examples: due to Audet and Dennis, slightly reworded (p. 87); the last assertion is new (p. 92); proof by Torczon (p. 85).

- **D8 Contribution & limits**:
  - *Contribution layers (pp. 168–169).* Theory: D-regularity; neighbors on the mesh identified as a required assumption; per-combination generating matrices; weaker hypotheses for MGPS; the FMGPS analysis. Algorithm: FMGPS; derivative pruning with {−1,0,1}^n. Software: NOMADm. Application: the thermal-insulation model extended with stress, mass and contraction constraints. Numerics: Ch. 7 and Ch. 8.
  - *Concrete limits.* The filter cannot ensure first-order stationarity and needs extra hypotheses (pp. 111–116, 170). Stalling by alternation is not excluded (pp. 117–118). Derivatives with nonlinear constraints are open: the NOMADm feasible-directions variant was slow and inaccurate on a simple problem, and KKT convergence is only conjectured (pp. 143–144, 171). FMGPS can be expensive for MVP, and NOMADm is too slow for runs with more intercepts (p. 142). Equalities are a problem in practice (p. 57).
  - *Future-research ledger (pp. 170–175), each item with a named obstacle:*
    - Filter: decrease h_max during the run, after Fletcher et al., to deal with blocking entries and the extra hypotheses (p. 170). KKT under a filter would need the tangent cone at the limit, hence infinitely many directions; the Coope–Price grid methods are named as a possible route (p. 170; Quote 2).
    - Derivatives under nonlinear constraints (p. 171).
    - Nonsmooth analysis: can GPS converge to a point with 0 ∉ ∂f when f is differentiable but not strictly differentiable (p. 171)?
    - Probabilistic analysis with random starting points and random poll directions, to avoid pathological cases (pp. 171–172).
    - Finite differences: after a failed 2n poll, form a central-difference gradient from the same evaluations and poll in one direction, saving 2n−1 evaluations (pp. 172–173).
    - Searching off the mesh, or on an ultra-fine mesh at machine precision (pp. 173–174).
    - Hybrids with simulated annealing on surrogates (pp. 174–175).
    - Computational studies, since the author finds no significant ones for GPS (p. 175).
    - A suite of expensive engineering blackbox test problems (p. 175).
    - NOMADm interfaces to C, C++ and AMPL (p. 175).
  - Reader's note (the link is to SKILL.md, not claimed by the thesis): several ledger items match later Audet work that SKILL.md lists. Infinitely many directions matches MADS 2006 (asymptotically dense directions). Decreasing h_max matches the progressive barrier 2009, whose Origin row in SKILL.md is marked as an inference. Random poll directions match LtMADS, later replaced by OrthoMADS 2009, co-authored by Abramson. The test-problem suite matches Method 4, and the multi-language interfaces match NOMAD (Method 6).

  - In the application, the Search is a poll around the least infeasible point (p. 135).
  - The Example 4.7 stall is cured by any reasonable nonempty Search (p. 65), and a two-point random Search finds the global minimizer in Example 8.19 (p. 163).
  - Variant ⚠: Ch. 8 puts the new idea (gradients) into the Poll by pruning it. The first rung is re-proved for directions that are evaluated or pruned (Thm 8.18, pp. 160–161), and the cheaper Polls often end at worse points (p. 164). So the Poll can change if the proof is redone.
  - The thesis also names the cost of forcing Search points onto the mesh: a surrogate optimum mapped to the mesh may not improve (p. 173). This is the limitation SKILL.md records under Method 1.
- Method 2 (Constraint semantics first): evidence ✅ (early form).
  - Three treatments are already distinct. Linear constraints are never violated, because points outside X are not evaluated (pp. 56–57). Nonlinear constraints are relaxable and measured by h in a filter with an h_max cap (pp. 66–67). Categorical discreteness must hold at every iterate (p. 14).
  - Evaluations that return no value are named (p. 15). The modeler eliminates equalities (p. 57). The stress constraint becomes an implicit equality and is eliminated by a monotonicity argument (pp. 130–131).
  - Variant ⚠: the class is decided by the form of the constraint (linear vs nonlinear), not by whether it is relaxable. Hidden constraints have no mechanism beyond f = ∞ (p. 16).
- Method 3 (Guarantee ladder, bounded by counterexamples): evidence ✅ (strong).
  - The hierarchy is announced in the abstract (p. 3) and summarized (pp. 95–96, 121–123). Hypotheses are weakened (D-regularity, pp. 52–55).
  - Necessity examples fence the results (pp. 53, 64–65, 86–87, 152). Extra hypotheses are surfaced rather than hidden (pp. 111–116). An open question is left explicitly open (p. 171).
  - Audet's counterexample work already existed as a 1998 report (TR98-24, p. 176).
- Method 4 (Real blackboxes → public benchmark artifacts): evidence ✅ (early form).
  - A joint Audet application is extended with realistic constraints (pp. 127–132).
  - MATLAB source for every test problem and for NOMADm is online (p. 186).
  - The thesis explicitly calls for a suite of expensive engineering blackboxes (p. 175).
  - Variant ⚠: there is no executable I/O contract and no best-known-solution record beyond the literature designs.
- Method 5 (Budget-aware, cross-community benchmarking): variant ⚠.
  - Present: separate counts of f- and gradient evaluations, a fixed cap, and perturbed restarts for fairness (pp. 162–164).
  - Missing: comparisons outside the family (only GPS poll variants), profiles; results are per-problem tables. The thesis itself notes that GPS computational studies and comparisons with other algorithms are missing (p. 175).
- Method 6 (The solver as research instrument): evidence ✅ (precursor).
  - NOMADm implements every algorithm in the thesis, with user files, a cache, LH search, hooks for user Search and surrogates, scaling, stopping criteria, live filter plots and derivative options (pp. 124–125).
  - The instrument also shapes results: the refinement schedule of [89] could not be reproduced (pp. 135–137), and NOMADm was too slow for runs with more intercepts (p. 142).
  - Planned C/C++/AMPL interfaces (p. 175).
- new-pattern candidate: **reduction-to-prior-cases design**. Every new rule collapses to the earlier algorithm's rule when the new feature is absent, so the earlier theorems become corollaries (pp. 69, 97, 116, 121, 168).
- new-pattern candidate: **user-defined neighborhood defines optimality**. For categorical variables, local optimality is relative to a user-given map N with a continuity condition, and the cost/globality trade-off of choosing N is stated (pp. 76–78, 133). SKILL.md's CatMADS and Workflow C step 2 are later forms.
- new-pattern candidate: **derivatives prune, not steer**. Derivative signs (exact, approximate or partial) remove poll directions, and a richer direction set makes the removal maximal (pp. 144–156).
- new-pattern candidate: **future-work ledger with named obstacles**. Each open problem names the mechanism that blocks it, for example the infinitely many directions needed for KKT under a filter (pp. 170–175).

**Transferable techniques**:
- Design every new trigger or acceptance rule so it reduces to the old rule when the new feature is absent; then prove only the new cases (pp. 97, 116).
- Get the first rung of any direct-search convergence ladder from f°(x̂;d) ≥ lim sup of the failed-poll quotients along a refining subsequence (p. 89).
- To exploit a known gradient sign in a direct search, poll from D = {−1,0,1}^n and keep only d̂ = sign(−∇f), completed by the ascent directions (which are never evaluated). Correct signs on the largest components of an approximate gradient are enough (pp. 149–156).
- When an extra hypothesis is needed, publish the list of algorithmic settings that make it automatic, as in Remark 6.23 (p. 116).
- In a filter method, cap h_max and keep the feasible incumbent out of the filter to avoid blocking entries (p. 67).
- Classify any extra exploration (polling other filter points, random samples) as Search, so the proof is untouched (p. 68).
- Validate a new model by reproducing published designs and explaining each discrepancy, then add constraints in stages to price each group (pp. 135–139).
- Remove a design variable by showing that the objective is monotone in it and that the constraint bounding it must be active at the optimum (pp. 130–131).
- Rerun any suspiciously short benchmark run from a perturbed start before crediting a strategy with it (p. 163).
