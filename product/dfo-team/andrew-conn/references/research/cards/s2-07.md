### S137 · The SIF Reference Report (revised version) (Online report 2003, no DOI/arXiv)
**Role**: supplement · **Coauthors**: N. I. M. Gould, D. Orban, Ph. L. Toint (p. 1) · **Position in trajectory**: This is the revised reference for the Standard Input Format that CGT created for LANCELOT (p. 2) and that CUTE problems are written in. Orban joins the original trio, which fits the CUTEr era, but the report does not say what was revised. **Read**: §1–§2 (pp. 2–10) in full; the §3 introduction (pp. 10–12); spot reads of START POINT (p. 34), the QUADRATIC footnotes (p. 36), OBJECT BOUND (p. 41) and the §4 introduction (pp. 43–44); §6–§8 (pp. 59–61) and the references (p. 62). The card-by-card syntax of §3.2, §4.2–§4.5 and §5 (pp. 12–58) was **not read** beyond those spots.

- **D1 Problem & entry**: The report starts from a practical bottleneck.
  - When there are thousands of variables, "merely the input of the problem data is extremely time-consuming and prone to error" (p. 2).
  - The format was motivated directly by the authors' own difficulties in entering LANCELOT test examples. If others were to test or use the software, "the process of specifying problems had to be considerably simplified" (p. 2).
  - It lists four reasons for a standard (pp. 2–3): consistency and reliability; automatic error and consistency checking; a portable, growing testbed; and the removal of recoding differences between codes, which are an obstacle to fair comparison (p. 2).
  - Precedents cited: NETLIB for LP and Harwell/Boeing for sparse linear algebra (p. 2).
  - Transferable technique: justify infrastructure work by the scientific failure it prevents (invalid comparisons between codes), not only by convenience (p. 2).
- **D2 Core idea & design**:
  - **Structure means invariant subspaces, not sparsity (p. 4).** (x₁ + … + x₁₀₀₀)² has a dense Hessian but still has a 999-dimensional invariant subspace. No nonlinear information is needed in that subspace (p. 4).
  - **Group partially separable form (2.1)–(2.4) (p. 5).** Each function is a group function gᵢ of a weighted sum of nonlinear element functions f_j plus a linear element. Each element depends on a small subset of the variables, or has a large invariant subspace for some other reason.
  - **Internal variables (p. 6).** A linear map u = Wv reduces elemental variables to internal ones. It is worth using only when W has fewer rows than columns.
  - **Types (p. 7).** Element and group *types* avoid defining structurally identical pieces one by one.
  - **Three files (pp. 10, 43–44, 61).** The SDIF file holds the structure and constants; it is an MPS superset, so an LP's SIF is just its MPS file (p. 10). The SEIF file holds element values and derivatives with respect to the internal variables only; elemental derivatives follow as Wᵀ∇ᵤf and Wᵀ∇ᵤᵤfW (p. 44). The SGIF file holds the group functions (p. 61).
  - **Optional sections.** Several named starting vectors (p. 34); known bounds on the objective (OBJECT BOUND, p. 41); QUADRATIC synonyms kept for compatibility with the MPS extensions of Ponceleón, Maros–Mészáros and OSL (p. 36).
  - **Free form (pp. 59–60).** Any free-form file must translate to fixed format in one sequential pass.
  - Transferable technique: when proposing a new standard, make it a strict superset of the de facto standard (MPS here). Old instances stay valid, and you list the unpleasant consequences you accept (p. 3).
- **D3 Assumptions & model**: There are no mathematical assumptions. The design constraints are stated as requirements (p. 3):
  - special structure (least squares, sparsity, partial separability) is a *mandatory* part of the description;
  - compatibility with MPS forces a fixed-format file;
  - the format must be independent of the operating system;
  - naming follows Fortran's six-character limit as "the most restrictive" popular language.
  - Stated weakness: modelling languages (GAMS, AMPL, OMP) remain the best way to enter large problems. But the authors "contend that there is at present no language in the public domain which satisfactorily handles the nonlinear aspects" (p. 3), so SIF is offered as a hoped-for "intermediate" step (p. 3).
- **D4 Analysis**: None; this is a format specification. The only mathematics is the chain rule from internal to elemental derivatives (p. 44).
- **D5 Experiments**: None.
- **D6 note**: The report positions SIF against three alternatives (p. 61).
  - Modelling languages handle repetitive structure but "do not really attempt to cope with useful nonlinear structure (like invariant subspaces)".
  - Factorable or functional forms (talks by Lenard and by McCormick–Rahnavard, 1989) could give automatic derivatives, but it is hard to describe how their building blocks are assembled. "We await further details" (p. 61).
- **D8 Contribution & limits**:
  - Contribution: infrastructure, three input files that feed both the optimizer's parameters and generated evaluation subprograms (p. 61). SIF is also "a first attempt to specify the minimal structures that should be present in a true modelling language" (p. 4).
  - Limits stated in the text: the formality "may admittedly appear formidable for very simple problems" (p. 2); free form places "considerable responsibility on the user" (p. 60).
  - The revision left early-1990s wording in place. The introduction says the community is only now designing algorithms for problems of this scale (p. 2), and "We have recently become aware" of the 1989 proposals (p. 61). A cross-reference says conclusions are "drawn in Section 7", but they are in §8 (pp. 4, 61).
  - No future work is listed beyond hoping for a real nonlinear modelling language (pp. 3–4).

**Method links**:
- Method 2 ✅ (evidence): the input format is presented as research infrastructure. Its stated purpose includes a portable, growing testbed and valid comparisons between competing codes (pp. 2–3). It also supports Heuristic 7 (release the input format with the solver), since it was born from LANCELOT testing (p. 2).
- Method 5 ✅ (evidence): exploitable structure is mandatory in the problem description ("the structure of least-squares problems must be described in an exploitable form", p. 3). Partial separability through invariant subspaces is the core concept (pp. 4–5).
- Method 1 ✅ (weak evidence): the format exists because the code had to be tested (p. 2).
- New-pattern candidate: **superset-of-incumbent standard**. Extend the de facto format (MPS) instead of replacing it, and accept its costs explicitly (p. 3).

**Transferable techniques**:
- Define "structure" by what the algorithm can save. Invariant subspaces mean no second-order information is needed there, which is a more useful criterion than sparsity (p. 4). Ask the same of your own problem class.
- Ask users for derivatives only in the smallest coordinates (internal variables), and let the software apply the linear maps (p. 44).

**Quotes**:
- "These differences could be a major obstacle to valid comparisons between competing optimization codes." (p. 2)
- "The importance of invariant subspaces is that nonlinear information is not required for a function in this subspace." (p. 4)

### S136 · Framework for large-scale modeling and simulation of electricity systems for planning, monitoring, and secure operations of next-generation electricity grids (Proceedings of the Computational Needs for the Next Generation Electric Grid 2011, no DOI/arXiv)
**Role**: supplement · **Coauthors**: J. Xiong, E. Acar, B. Agrawal, G. Ditlow, P. Feldmann, U. Finkler, B. Gaucher, A. Gupta, F.-L. Heng, J. R. Kalagnanam, A. Koc, D. Kung, D. Phan, A. Singhee, B. Smith (IBM Smarter Energy Research, p. 1) · **Position in trajectory**: Conn's IBM energy period. This is a team white paper answering a DOE RFI ("This RFI report", p. 1). Which author wrote which section is not stated, so nothing below is attributed to Conn personally. §2.5 (optimization methods) cites five Conn works ([75], [76], [77], [80], [84]; pp. 13, 61–62) and a MINLP paper he coauthored ([121], pp. 13, 64). **Read**: Ch. 1 (pp. 1–2) and Ch. 2 (pp. 3–19) in full; Ch. 3 only §3.1's opening (pp. 19–20) and §3.5 (pp. 35–36); Ch. 4 §4.1 (pp. 36–38), the start of §4.3 and §4.3.1 (pp. 44–46), and §4.4 (pp. 53–54); Ch. 5 (pp. 54–56); the Ch. 2 reference list (pp. 57–62) scanned. §3.2–§3.4, §4.2 and §4.3.2–§4.3.4 **not read**.

- **D1 Problem & entry**: The entry is the operator's pain at real scale.
  - The grid is "aging, is inefficient, congested" and operates closer to its transfer limits, so it needs better situational awareness (p. 1).
  - Three areas are named: security-constrained unit commitment (UC) and economic dispatch (ED) with stochastic analysis; massive data management; and large-scale grid simulation (p. 1).
  - The scale gap is stated with numbers (pp. 3–4). Commercial IP solvers handle UC with about 100 units, 24 periods and 50 scenarios. Real instances have thousands of buses, more than 1000 generators, 48–72 periods, more than 100 contingencies and hundreds of scenarios.
  - Six limitations of current solutions are listed, from failing time limits to the lack of real-time support (p. 4).
  - Transferable technique: state the gap between the literature's instance sizes and the users' real sizes with concrete counts before proposing anything (pp. 3–4).
- **D2 Core idea & design**: This is a survey and agenda, not an algorithm.
  - The central recommendation is a hybrid-computing environment for three things: parallel scenario evaluation, parallel decomposable formulations, and large-scale optimization "with guaranteed convergence to high quality solutions" (p. 5).
  - Method-choice advice in §2.5 (pp. 12–14):
    - Modelling languages with automatic differentiation are useful (p. 12). IPOPT is described as "One of the best implementations of interior‐point methods" (p. 12).
    - Without derivatives, one "typically cannot expect to solve problems on a serial machine with more than about 200 variables" (p. 13).
    - Simulated annealing, genetic algorithms and Nelder–Mead are "rarely the best ones to use" (p. 13), although they and particle swarm are often used in power systems (p. 14). McKinnon's Nelder–Mead non-convergence paper is cited [89] (pp. 13, 62).
    - Under significant noise, finite-difference gradients are a bad idea (p. 14).
  - Wording inconsistency: p. 13 lists automatic differentiation among the ways a "derivative‐free method" approximates derivatives. Ch. 4 instead describes AD as giving exact derivatives "correct by construction" and as under-used in grid computation (p. 46).
- **D3 Assumptions & model**: No formal model. Two stated theoretical cautions:
  - Generalized Benders decomposition applied to the nonconvex SCED lacks a convergence analysis, and there is "no established theoretical guarantee that it can provide a local minimizer" (p. 10).
  - Benders "cannot guarantee either convergence or optimality" under AC non-convexity, and no theory shows the iterates reach a feasible point even in the limit (p. 19).
- **D4 Analysis**: None.
- **D5 Experiments**: None. Figures such as a speedup of more than 10 times on 16 processors are quoted from the literature ([51], p. 11).
- **D6 note**:
  - Conn's own books are recommended for non-experts. *Trust-Region Methods* is "the encyclopedic text [75] for which some chapters are accessible to the non‐expert". The DFO book is "intended to be both comprehensive and readily accessible to the non‐expert" (p. 13).
  - LANCELOT is presented next to ALGENCAN: "The two most popular packages" for augmented-Lagrangian methods (p. 13).
  - Engineers are criticised mildly: "many a time engineers use algorithms that do not represent state‐of‐the‐art optimization techniques", hence the call to bring mathematicians and engineers together (p. 19).
  - A careless reference: [87], cited for "genetic algorithms", is a paper on a parallel maximal-independent-set algorithm (pp. 13, 62).
- **D8 Contribution & limits**:
  - Contribution: an agenda. The future directions are real-time UC/ED with thousands of generators; joint UC plus AC-based ED as a MINLP solved by decomposition; stochastic SCUC/SCED that exploits structure ("most of these problems are highly structured", p. 17); and large-scale optimization with convergence guarantees (pp. 15–19). Ch. 5 adds a "virtual power grid" calibrated from streaming data (pp. 55–56).
  - On theory versus practice: most theoretical results "are oriented toward the asymptotics", but engineers rarely operate in that regime (p. 18). Finding better solutions than the known ones "can be considered successful" (p. 18).
  - Limits: the paper presents no method and no data of its own.

### S065 · On the local convergence of a derivative-free algorithm for least-squares minimization (Computational Optimization and Applications 2012, DOI 10.1007/s10589-010-9367-x)
**Role**: supplement · **Coauthors**: Hongchao Zhang (LSU); Conn at IBM T.J. Watson (p. 1). Scheinberg is thanked for comments (p. 26). · **Position in trajectory**: the second of the DFLS papers. The first, Zhang–Conn–Scheinberg (SIOPT 2010, [20]), proved global convergence and studied performance under a limited budget (p. 1). A bound-constrained version, DFBOLS, is "in preparation" ([21], pp. 26–27). Received 20 July 2010, online 23 October 2010 (p. 1). **Read**: the whole paper (pp. 1–27).

- **D1 Problem & entry**: The paper completes the theory of an existing algorithm.
  - Global convergence and limited-budget numerics were settled in [20]. This paper adds the local rate and the long-run numerics (p. 1).
  - The problem is min ½‖F(x)‖², where F is twice continuously differentiable but no first or second derivatives are available (p. 2).
  - The rate is proved under a local error bound, which is "considerably weaker than a non-singularity assumption on the Jacobian" (p. 2).
  - Transferable technique: split one algorithm's analysis into a global paper and a local paper, and match each with its own numerical regime: small budget for the first, huge budget and high accuracy for the second (pp. 1, 20–21).
- **D2 Core idea & algorithm design**:
  - **Models.** DFLS builds one interpolation model mᵢ per residual fᵢ on a shared set of typically 2n+1 points, using Powell's minimum-Frobenius-norm updates. The update cost is O(mn) and model building costs O(mn²) per iteration, apart from occasional origin shifts at O(mn³) (p. 2).
  - **Model Hessian with three cases (p. 4).** It is Gauss–Newton JᵀJ when the model gradient is large; the regularized JᵀJ + κ³_H‖m‖I when the gradient is small and the residual is small relative to it; and the full JᵀJ + Σ mᵢ∇²mᵢ otherwise.
  - **Algorithm Steps 0–6 (pp. 5–7).** A criticality step with a Λ-poisedness radius proportional to ‖g‖; a trust-region subproblem, with the model built at a base point yₖ but centred at xₖ (footnote p. 5); a safety step; acceptance when rₖ > 0; the radius update, whose thresholds 0.1 and 0.7 are "somewhat arbitrary" (footnote p. 6); and model improvement.
  - **New in this paper.**
    - Assumption 3.2 restricts attention to the subclass in which the base point is eventually the current iterate (p. 9).
    - The paper then shows that DFLS eventually reduces to a regularized Levenberg–Marquardt-type algorithm (pp. 9, 16), which lets it reuse the Fan–Yuan analysis (p. 17).
  - **Kept.** The algorithm of [20] is unchanged. The implementation sits on NEWUOA's framework, "partly because the details in NEWUOA are carefully and intelligently chosen", and partly to make the comparison with NEWUOA more meaningful (p. 20).
- **D3 Assumptions & model**:
  - A2.1: the level set is bounded (p. 7).
  - A2.2: the model Hessians are uniformly bounded (p. 8).
  - A3.1: zero residual, plus the local error bound ‖F(x)‖ ≥ α dist(x, X*). This allows singular Jacobians and non-isolated solutions (pp. 8–9).
  - A3.2: the base point is eventually xₖ (p. 9).
  - A3.3: the iterates converge to the solution set X*. This is **assumed, not proved**: "Assume the sequence of {xk} generated by the DFLS algorithm converges to the solution set X∗" (p. 9).
  - Λ-poisedness is used in either the interpolation or the minimum-Frobenius-norm sense, which are equivalent up to the constant (Definitions 2.1–2.2, pp. 3–4).
- **D4 Analysis & proof technique (brief)**:
  - Lemma 3.1: the criticality step makes the model-Jacobian error at most a constant times ‖g_φ‖, which is at most L₃·dist(xₖ, X*). The certified-model property thus becomes an error that is proportional to the distance to the solution set (p. 10).
  - Lemma 3.2: the error bound plus Taylor expansion give c_φ ≤ cδ‖g_φ‖. Eventually the regularized branch is chosen, and the model is ½‖m + ∇m d‖² + λₖ‖d‖² with λₖ ∝ ‖F(xₖ)‖ (pp. 10–12).
  - Lemma 3.3: ‖dₖ‖ ≤ 2·dist(xₖ, X*), proved by comparing with the feasible point x̄ₖ − xₖ (pp. 12–13).
  - Lemma 3.4: |rₖ − 1| → 0 and Δₖ ≥ Δ̄ > 0. So the safety and model-improvement steps stop firing and the trust region becomes inactive (pp. 13–16).
  - Theorem 3.5: superlinear convergence, through ‖x_{k+1} − x̄_{k+1}‖ ≤ C‖xₖ − x̄ₖ‖^{3/2} (pp. 16–17).
  - Lemma 3.6 and Theorem 3.7: an SVD split of ∇m(xₖ) into a rank-r part, a vanishing part and a zero part gives quadratic convergence, ‖d_{k+1}‖ = O(‖dₖ‖²). The proof of Lemma 3.6 is omitted as "directly" following [8] (pp. 17–20).
- **D5 Experiments**: DFLS against LMDIF (finite-difference Levenberg–Marquardt) and NEWUOA, on four test sets (pp. 20–26).
  - Setup: Fortran compiled with F77 on an IBM ThinkPad T40; 2n+1 points; initial radius 1.0; a cap of 10⁵ evaluations, "rather large" on purpose (p. 21).
  - Zero-residual set (25 problems): 15 equality-constrained Hock–Schittkowski problems recast as least squares, plus problems "collected from a variety of places during the development" (p. 21). The stopping test is stringent (4.1) (p. 21). DFLS uses 1/5 to 1/10 of NEWUOA's evaluations (Table 1, p. 22).
  - Nonzero-residual set (22 problems): HS problems whose first residual is the objective "plus ten" when the optimum is zero, to force a nonzero residual (p. 22; Table 2, p. 23).
  - Noisy sets: absolute noise 10⁻²E and relative noise, 10 runs each. The final trust-region radius and the finite-difference step are set to the noise level. The best noise-free value is reported (Tables 3–4, pp. 23–26).
  - Reporting marks: "*" means convergence to a different local optimum and "F" means failure (pp. 21, 24).
  - Hedge: "a more challenging set of test problems should be tested" (p. 22).
- **D6 note**: The conclusion reconciles the result with [20]. Under a small budget, LMDIF had been less affected by noise and instability, probably because it fully uses the least-squares structure while NEWUOA cannot build accurate models early (p. 26).
- **D8 Contribution & limits**:
  - Contribution: theory (a local quadratic rate under an error bound) plus long-run numerics. Recommendation: interpolation-based methods over finite differences when high accuracy is needed (p. 26).
  - Limits:
    - The rate covers zero-residual problems only.
    - Convergence to X* is assumed (A3.3), and only a subclass is analysed (A3.2).
    - The test set is small and partly ad hoc (pp. 21–22).
    - Exploiting structure costs about O(mn²) extra storage relative to NEWUOA, "which is the cost of exploiting the structure" (p. 21).
  - Future: global and local convergence of DFBOLS (p. 26).

**Method links**:
- Method 5 ✅ (evidence): one model per residual; the conclusion credits the gains to using both interpolation models and least-squares structure (pp. 2, 26). Heuristic 2 is instantiated exactly.
- Method 3 ✅ (evidence, extension): the criticality step's Λ-poisedness radius, proportional to ‖g‖, is what turns fully-linear accuracy into an error of order dist(x, X*). The certified model carries the *local rate*, not only global convergence (p. 10).
- Method 1 ✅ (evidence): a theorem paper with its own three-code numerical study, paired with the global-convergence paper [20] (pp. 1, 20–26).
- Method 6 ✅ (evidence): local-rate machinery for Levenberg–Marquardt under error bounds (Fan–Yuan; Yamashita–Fukushima) is transplanted into DFO (pp. 9, 17).
- Method 2 ⚠ (variant): the cost unit is function evaluations and noisy variants are included, but the test set is Hock–Schittkowski reformulations plus problems collected during development, not a public DFO collection (pp. 21–22).
- New-pattern candidate: **reduce-to-classical local analysis**. Prove that the safeguards eventually switch off, so that the DFO method *is* a known classical iteration, then import that iteration's local proof (pp. 13–17).

**Transferable techniques**:
- To get a local rate for a trust-region/model-based method, prove |rₖ − 1| → 0 and a radius bounded away from zero. Then the trust-region constraint is inactive and the step is the classical step (pp. 13–17).
- Replace Jacobian nonsingularity by a local error bound ‖F(x)‖ ≥ α dist(x, X*). This covers non-isolated solutions at little extra cost in the proof (p. 9).
- Build a zero-residual test set with known optima by recasting equality-constrained NLP problems: (objective − optimal value) becomes the first residual and the equality constraints the others. Add a constant to make it nonzero-residual (pp. 21–22).
- In noisy comparisons, set every solver's final resolution (trust-region radius, finite-difference step) to the noise level, and report the best *noise-free* value over 10 runs (pp. 23–24).

**Quotes**:
- "Here we would like to establish the local quadratic convergence of the algorithm for zero residual problems." (p. 1)
- "although a more challenging set of test problems should be tested to confirm the promise." (p. 22)

### S060 · Lagrangian relaxation based decomposition for well scheduling in shale-gas systems (Computers & Chemical Engineering 2014, DOI 10.1016/j.compchemeng.2014.02.005)
**Role**: supplement · **Coauthors**: B. R. Knudsen (NTNU, corresponding author), I. E. Grossmann (CMU), B. Foss (NTNU); Conn at IBM T.J. Watson (p. 1) · **Position in trajectory**: the IBM–NTNU energy collaboration. Funding came from the Center for Integrated Operations in the Petroleum Industry (Trondheim) and an IBM PhD scholarship, and Whitson (NTNU) is thanked (p. 27). The earlier Knudsen–Foss–Whitson–Conn proxy model paper is cited as [11] (p. 27). Conn's own part cannot be identified from the text. **Read**: the whole preprint (pp. 1–30), including Appendix A.

- **D1 Problem & entry**: The entry is an application problem.
  - Liquid loading degrades late-life shale-gas wells. Whitson et al. showed that short cyclic shut-ins remove it (pp. 1–2).
  - Earlier work posed shut-in scheduling for one multi-well pad as a MILP with proxy models. For a whole field this becomes computationally prohibitive (p. 2).
  - The structural observation: pads are coupled only weakly, which suggests Lagrangian relaxation (p. 2).
  - Four requirements are set out (p. 3): a stable multiplier method, a primal heuristic, accurate and cheap proxy models, and a good formulation.
- **D2 Core idea & design**: Six components, each chosen for the scheme to work at field scale.
  - **Proxy model.** A three-region radial composite reservoir model in pseudopressure, discretized into (4) (pp. 4–6).
  - **Tuning.** The proxy is fitted by weighted nonlinear least squares against a 4200-cell SENSOR reference model (pp. 7–9):
    - the *prediction errors* are passed through a 2nd-order Butterworth low-pass filter, so that the fit emphasises the post-shut-in transients the scheduler exploits;
    - the min() in the well model is smoothed;
    - c_tran ≤ c_f acts as a regulariser;
    - multistart is used because the fit is nonconvex.
  - **Model update.** An MHE-type re-fit with a forgetting factor P̂_{k+1} = α_I P̂ₖ, so that old shut-in data is forgotten rather than accumulated (pp. 10–11).
  - **Formulation.** From a GDP model (12) to a MILP (18): a hull reformulation for (13a) and big-M for (13b). A full hull reformulation was slower and improved the LP relaxation only marginally (p. 14). The minimum up- and down-time constraints are projections of known turn-on/off inequalities (pp. 15–16).
  - **Decomposition.** Dualizing the single linking constraint Σ q_ref_l = q_REF gives one MILP per pad (p. 16).
  - **Dual solver** (Algorithm 1, pp. 18–19): a cutting-plane method stabilised by a trust region, which the paper calls "closely related to the boxstep method".
    - A serious step is taken only if Z_LR(λ^{n+1}) ≥ Z_LR(λ̄) + σρ̃, with σ = 0.01.
    - The ratio ρ of actual to predicted increase sets the radius: ×1.5 if ρ = 1, ×0.8 if ρ < 0, changed only when λ is on the boundary.
    - A 1-norm region keeps the master problem an LP.
    - The bound λ ≥ −1 comes from Appendix A.
  - **Primal heuristic** (pp. 19–20): fix the binaries from the subproblems and solve an LP for the pad reference rates. Then run a local-branching search (Fischetti–Lodi) with Hamming radius r = ⌈|K||J|/3⌉, increased by 50% up to five times when infeasible, and a 15–90 s cap.
  - Transferable technique: when a dual or cutting-plane method oscillates, stabilise it with a trust region and a ratio test between actual and predicted improvement, exactly as in nonlinear programming (pp. 18–19).
- **D3 Assumptions & model**:
  - The proxy is valid only while the rate stays at or above the critical rate, which avoids a multiphase model (p. 6).
  - Compressibility is constant within each region (pp. 7, 9).
  - The reference rate is constant ("Without loss of generality", p. 12).
  - The Lagrangian feasible set is a polytope "by assumption" (p. 17).
  - Each well has independent closed-loop wellhead-pressure control, so exact tracking "will almost certainly be impossible" (p. 25).
- **D4 Analysis (brief)**:
  - The Lagrangian bound is at least as tight as the LP relaxation (p. 16).
  - Z_LR is concave and piecewise linear, and the cutting-plane method converges finitely but is unstable (p. 17).
  - Appendix A proves λ ≥ −1 through LP duality and Fourier–Motzkin elimination on a simplified subproblem (pp. 29–30).
  - Any λ ≥ 0 gives the a priori solution q_ref = 0, which is added to the initial cutting-plane model (p. 19).
  - There is no convergence proof for the whole scheme.
- **D5 Experiments**:
  - Setup: nine sets, 3/6/9 pads × 7/14/21 days, six wells per pad, three permeabilities (pp. 20–22). GAMS with CPLEX 12.3 on a laptop with 8 threads (p. 22). The baseline is the full-space MILP given about the same wall time (p. 22).
  - Duality gaps: 0–22.9% for the Lagrangian scheme against 63.3–100% for the full-space solve. Six of the nine full-space runs end with a 100% gap, meaning the lower bound stays near zero, and two run out of memory (Table 4, p. 23). The Lagrangian upper bound is better on all nine sets (p. 23).
  - The dual converges in 4–9 iterations (p. 24).
  - The gap as a function of q_REF is plotted in Fig. 8 (pp. 23–24).
  - Self-assessment: judged by the gap alone, performance is "only average" (p. 22).
- **D8 Contribution & limits**:
  - Contribution: a decomposable scheme built from a GDP model, plus a frequency-selective proxy tuning and update method (pp. 24–26). The scheme is scalable in the number of pads (p. 27).
  - Limits:
    - duality gaps above 10% on several sets, depending on the configuration (pp. 22, 25);
    - weaker efficiency for long horizons (p. 27);
    - a nonconvex tuning NLP (p. 26);
    - proxy mismatch after short shut-ins (p. 12).
  - Future directions are specific (pp. 25–26):
    - augmented-Lagrangian decomposition, or branch-and-price;
    - Lagrangian *decomposition* (Guignard–Kim) for tighter bounds;
    - per-well bilevel decomposition, which needs an ℓ1/ℓ∞-type objective;
    - temporal decomposition;
    - grid-computing parallelism;
    - quadratic stabilization when the number of dual variables grows.

**Method links**:
- Method 4 ✅ (evidence): the problem comes from petroleum operations through the NTNU/IO-center partnership, with a petroleum engineer consulted, and appears in a chemical-engineering venue (pp. 1, 27).
- Method 6 ✅ (evidence): the trust-region ratio-test logic is transplanted from NLP to stabilise a Lagrangian cutting-plane dual (pp. 18–19). Local branching and GDP reformulations are borrowed from MIP (pp. 13–14, 20).
- Method 5 ✅ (evidence): the block-separable structure with one linking constraint is exploited (p. 16). The surrogate is built and tuned for exactly the dynamics the decisions act on (pp. 6–9).
- Method 1 ⚠ (variant): algorithm plus numerics, but the only theory is a multiplier bound (Appendix A). There is no convergence claim for the scheme.
- Method 2 ⚠ (variant): the instances are generated from the authors' own proxy, not taken from a public set. The baseline is a same-time full-space solve (pp. 20–22).
- New-pattern candidate: **fix the discrete decisions from a cheap solve, then repair**. Binaries from the relaxed subproblems are fixed, an LP recovers feasibility, and local branching polishes the result (pp. 19–20). The same move appears in S099.

**Transferable techniques**:
- Fit a surrogate by filtering the *prediction errors* with a frequency filter tuned to the time scale your decisions act on, rather than by fitting all dynamics equally (pp. 7–9).
- When updating a surrogate whose validity is local in time, give the prior-weight matrix a forgetting factor instead of an arrival cost, so that old data fades (pp. 10–11).
- Before running a cutting-plane dual, derive bounds on the multiplier that keep the subproblems bounded (here by Fourier–Motzkin elimination), and seed the model with known a priori solutions (p. 19; Appendix A).
- Compare a decomposition against the monolithic solve *given the same wall time*, and report both bounds, not only the incumbent (pp. 22–23).

**Quotes**:
- "For field-wide multi-pad systems, however, the dimensionality of the MILP becomes computationally prohibitive." (p. 2)
- "Hence, if only evaluated by size of the duality gap, the performance of the Lagrangian relaxation scheme applied to these sets may be considered as only average." (p. 22)

### S099 · Mixed-integer nonlinear and continuous optimization formulations for aircraft conflict avoidance via heading and speed deviations (European Journal of Operational Research 2023, DOI 10.1016/j.ejor.2023.03.002)
**Role**: supplement · **Coauthors**: S. Cafieri, M. Mongeau (ENAC) · **Position in trajectory**: a posthumous paper. The title footnote reads "In memory of our dearest friend Andy Conn" (p. 2), and Barbara Conn is thanked for proofreading (pp. 21–22). It is the journal outcome of S166 and relies on the companion report "The continuous quadrant penalty formulation of logical constraints" by Cafieri, Conn and Mongeau (HAL 2022, [11], p. 23). **Read**: the whole paper (pp. 1–24).

- **D1 Problem & entry**:
  - Pairwise separation is a hard constraint. The problem "is in fact a feasibility problem", made into an optimization problem by secondary criteria such as minimal deviation (p. 3).
  - Literature gap: most models use only speed or only heading (p. 3). For face-to-face aircraft, speed regulation alone cannot work (p. 3).
  - The only fully continuous earlier model, by Peyronne, Conn, Mongeau and Delahaye [25], is criticised: it finds local optima only and relied on finite differences (p. 3).
  - Target: instances "not solved in [17, 26]", the recent MIQCP work of Rey–Hijazi and Dias et al. (p. 4).
- **D2 Core idea & design**:
  - **Parabola approach [13] (pp. 5–6).** Separation for all t ≥ 0 is equivalent to a logical condition: if t^m_ij > 0 then ‖v‖²(‖x⁰‖² − d²) − (x⁰·v)² ≥ 0. Geometrically, the lowest point of the parabola must avoid the open fourth quadrant S.
  - **Change of variables (pp. 6–8).** (qᵢ, θᵢ) is replaced by (qᵢ, ωᵢ, πᵢ), with ω = cos(φ+θ)qv and π = sin(φ+θ)qv. The relative velocity (10) becomes linear, and only one quadratic equality ω² + π² = (qv)² (11) remains per aircraft. This avoids trigonometric functions and removes the bilinear products cᵢqᵢ and sᵢqᵢ (p. 8).
  - **Objective without trigonometry (pp. 8–10).** An auxiliary bᵢ ≥ |sin θᵢ| is minimized. Four sign cases of the known data φᵢ give bilinear linking constraints (20)–(25), and valid bounds on ω and π are derived for branch-and-bound (pp. 9–10).
  - **MINLP (33)–(47) (p. 11).** The logical constraint is written in complementarity form, t^m(y − 1) ≥ 0 and y·(…) ≥ 0 (pp. 8, 11).
  - **NLP-Penalty (54)–(60) (pp. 11–14).** It minimizes Σ g_β(t^m, f^m), where g_β is the smooth, piecewise-quadratic "continuous quadrant penalty" from [11] with β = 3. The model is feasible (q = 1, θ = 0) and bounded below by 0 (p. 14).
  - **Three-phase method** (Algorithm 1, pp. 19–20), with λ = 0 because controllers prefer heading changes, which they can see on their displays (p. 19):
    - Phase 1 solves NLP-Penalty with multistart to get a conflict-free point, and computes the binaries y and the speed deviation, which becomes an upper bound.
    - Phase 2 fixes y and solves a continuous nonconvex global problem with that cutoff.
    - Phase 3 solves the full MINLP from the incumbent with the cutoff.
- **D3 Assumptions & model** (pp. 5–7):
  - all aircraft fly at one flight level on straight lines at uniform speed;
  - all maneuvers are simultaneous at t = 0;
  - aircraft are initially separated, which is checked in preprocessing;
  - v_ij ≠ 0 without loss of generality.
  - Speed stays within [0.94, 1.03]·v ("subliminal") and heading changes within ±π/6, both as in ATC practice (pp. 7, 14).
  - Altitude changes and trajectory recovery are excluded (p. 4).
- **D4 Analysis (brief)**:
  - The continuous-time constraint is equivalent to the logical condition by strict convexity of f_ij (p. 6).
  - Size counts: O(3n²/2) variables, including n(n−1)/2 binaries (p. 11).
  - An explicit caveat: each penalty term leans outward from S, but the sum does not. It is non-separable and nonconvex, and it may have local minima that violate the separation constraints (p. 14).
  - There is no convergence theory.
- **D5 Experiments** (pp. 13–21):
  - Instances: the literature's Circle Problem (CP) and Random Circle Problem (RCP) sets, taken from [17, 26].
  - Tools: AMPL; COUENNE 0.5 with bound tightening turned off and a 600 s limit; IPOPT 3.12 with MA57. λ = 10⁻⁶ is justified by the 3–4 orders of magnitude difference in scale between the two criteria (p. 14).
  - MINLP: global optima for CP up to n = 19 in under 4 s, where [17, 26] had only local optima for n = 11–19; all 10- and 20-aircraft RCP instances; 7 of the 15 30-aircraft RCP instances (Table 1, pp. 15–16).
  - NLP-Penalty: zero penalty on all 34 RCP instances, 32 of them in one run (Table 2, pp. 17–18).
  - Three-phase method: 14 of the 15 RCP-30 instances solved to global optimality, 12 without needing Phase 3, and 8 in under a minute in total (Table 3, pp. 20–21).
- **D8 Contribution & limits**:
  - Contribution: two models and a method that combines continuous local optimization (efficient bounds) with branch-and-bound (a proof of global optimality). NLP-Penalty "yields efficient computation of good quality upper bounds" (p. 21).
  - Limits: local infeasibility of the penalty model (pp. 14, 17); one instance unsolved (p. 20); simultaneous maneuvers only; no trajectory recovery (p. 4).
  - Future: autonomous vehicles and non-simultaneous maneuvers in a dynamic environment (p. 21).

**Method links**:
- Method 6 ✅ (evidence): a penalty function, Conn's oldest tool, is reused as the engine of a global method. The local NLP supplies incumbents and cutoffs, and fixes the integer decisions, for the global MINLP (pp. 17–21).
- Method 5 ✅ (evidence): the change of variables and sign-case reformulation remove trigonometry and bilinear terms, and valid bounds are derived before any solver runs (pp. 7–10). The paper also criticises the earlier continuous model's use of finite differences (p. 3), consistent with Heuristic 1.
- Method 4 ✅ (evidence): operational practice drives the model: subliminal speed bounds, ±π/6 headings, and controllers' preference for heading changes (pp. 7, 14, 19).
- Method 2 ✅ (evidence, adopt rather than build): the test instances are public literature instances from competing groups ([17, 26], p. 14), which is the adoption route that Method 2's Limitations recommend.
- New-pattern candidate: **fix the discrete decisions from a cheap solve, then repair or prove** (Phases 1→2→3, pp. 19–20; compare S060 pp. 19–20).

**Transferable techniques**:
- Replace an angle and speed pair by velocity components plus one quadratic equality. The relative velocities become linear and all trigonometry disappears. This works for any problem with rotating or steered objects (pp. 6–8).
- Use known sign data to turn min/max expressions of trigonometric data into bilinear constraints and valid variable bounds before branch-and-bound (pp. 8–10).
- Chain the solvers: a fast smooth penalty model finds a feasible point, whose objective becomes the cutoff and whose implied binaries are fixed; then solve the restricted problem globally; unfix only if needed (Algorithm 1, p. 20).
- When a penalty's per-term property (leaning outward from the forbidden set) does not survive summation, say so explicitly and use multistart (p. 14).

**Quotes**:
- "Moreover, the authors could not achieve computing explicit derivatives, therefore resorting to finite-difference approximations." (p. 3)
- "In particular, the proposed NLP-Penalty model yields efficient computation of good quality upper bounds." (p. 21)
