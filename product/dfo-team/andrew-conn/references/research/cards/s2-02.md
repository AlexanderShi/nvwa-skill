# Paper cards · batch s2-02 (supplement)

Batch intent: See how Conn, around 1988–1991, turned one structural insight into two kinds of output: algorithms and shared infrastructure. Three items come from the Conn–Li nonlinear minimax programme: the 1989 Waterloo report, the 1990 Cornell report and the 1992 SIOPT article. That programme builds a descent algorithm for nonlinear minimax and Chebyshev problems out of the *characterisation* of the solution (the generalised alternation property). The fourth item is the CGT tutorial on the Standard Input Format (SIF). The SIF made the structure of a large nonlinear problem a shareable input for LANCELOT and its test collection. The batch tests Method 5 (structure before black box), Method 6 (carry linear Chebyshev theory and NLP machinery into a new setting), Method 1 (theory–code–test) and Method 2 (test bed).

### S164 · An Approach to Nonlinear Approximation (University of Waterloo, Dept. of Computer Science, Research Report CS-89-21, Dec. 1989; no DOI/arXiv)
**Role**: supplement · **Coauthors**: Yuying Li · **Position in trajectory**: The cover title is *An Approach to Nonlinear l∞ Approximation* (p. 1). This is the details report of the Conn–Li minimax cluster. It restates the method of CS-88-41 (ref. [7], the Waterloo version of S108) and the characterisation report CS-88-39 (ref. [8]). It then adds the line search, the degeneracy handling and the Maratos safeguard. All proofs are delegated to Li's 1988 Waterloo PhD thesis (ref. [13]), with page pointers (pp. 2, 23). **Read**: all 24 pages, from page images.

- **D1 Problem & entry**:
  - Problem: the discrete Chebyshev problem min_x max_i |f_i(x)|, possibly a discretisation of a continuous approximation problem over a compact set T. The f_i are C² and a local minimum is sought (pp. 2–3).
  - Standard route: add one variable z and solve the equivalent NLP. The authors instead want to exploit the structure of the *optimal solution*, because classical Chebyshev theory characterises solutions of linear problems. That characterisation has been exploited very successfully in practice by Barrodale–Phillips and by Bartels–Conn–Li (p. 3).
  - Stated obstacle: the linear case has a *global* characterisation that is easy to compute with, while the nonlinear case in general does not. The algorithm is therefore built on *local* attempts at characterisation, which in the limit give the correct one (p. 3).
  - Earlier attempts to generalise the alternant to nonlinear problems (Motzkin, Rice, Tornheim) are called restrictive and hard to exploit computationally (p. 5).
  - Origin, per the conclusion: the first author's experience with the Charalambous–Conn 1978 descent algorithm (ref. [5]). Its efficiency is impeded when two or more activities belong to the same peak of the error curve. That cannot happen at a Chebyshev *solution*, so imposing the solution's structure should help (p. 21).
- **D2 Core idea & algorithm design**:
  - Generalised objects: Descloux's linear *cadre* is generalised to sets of gradients at the current x (Def. 3, p. 6). Cadre multipliers are normalised to sum to 1 (type 1) or to 0 (type 2) (Def. 4, p. 7). A reference set has positive multipliers and same-sign function values; a *levelled* reference set also has equal function values (Def. 6, p. 7).
  - Optimality restated: a local minimiser carries a levelled reference set with the maximum deviation (Thm 2.3, p. 8).
  - Procedure: (1) find a cadre, (2) build a reference set on it, (3) level it, all inside a descent method with a line search (p. 8).
  - Working set: the ε-active functions plus a subset of the previous working set, kept so that A = [∇f_{i0} − ∇f_{ij}] has full rank (p. 9).
  - Direction: d = h + v when v is a descent direction, otherwise h (16)–(17). The horizontal part h = −ZB⁻¹Zᵀ∇f_μ descends. The vertical part v = −A(AᵀA)⁻¹Φ levels the working functions (p. 10).
  - Dropping: negative cadre multipliers drop several indices at once, which the authors call *multiple dropping* (p. 10).
  - Kept: the NLP-style projected-Hessian step and a line search on ψ. Changed: the working set targets a reference set rather than an active set, and levelling is an explicit direction component (pp. 9–10).
- **D3 Assumptions & model**:
  - f_i ∈ C². Local minimum only (p. 3).
  - Assumption 4.1: Lipschitz gradients, used by the line search (p. 11).
  - B is positive definite (p. 10), and Lemma 4.2 needs a bounded set of directions (p. 12).
  - For simplicity, ε is taken small enough that A(x,ε) = A(x,0), which the authors say loses no generality because there are finitely many f_i (p. 15).
- **D4 Analysis (brief)**: No proofs are given; the abstract says all proofs are omitted to emphasise the main ideas, and each result points to a page of Li's thesis (p. 2). The results cited are:
  - first-order conditions (Thm 2.2) and their restatement as a levelled reference set (Thm 2.3) (p. 8);
  - h and v do not depend on the choice of representative index i0 (Thm 3.4, thesis p. 61) (p. 10);
  - line-search acceptance: a δ-condition (sufficient decrease measured by the ε-active one-sided derivative ∇ψ⁻_ε) plus either a β-condition (curvature on a decreasing active piece) or a γ-condition (closing the gap on a non-decreasing piece) (p. 11);
  - an acceptable step interval exists, the step is bounded below by min{−ζ∇ψ⁻_ε, η}, and the first minimum along d is acceptable (Lemmas 4.1–4.3, thesis pp. 160–167) (p. 12);
  - how to tell the degeneracy types apart (Lemmas 5.1–5.2, thesis pp. 110–112) (p. 15), and an NNLS reformulation (Lemma 5.3, thesis p. 120) (p. 19).
  - The conclusion states global convergence with two-step superlinear convergence under certain conditions (thesis p. 191) (p. 21).
- **D5 Experiments**: None in this report. The conclusion says initial testing indicated the efficacy of the method and points to [7] for details (p. 22).
- **D8 Contribution & limits**:
  - Contribution: algorithmic engineering on top of a characterisation theory: a safeguarded line search with cubic or quadratic interpolation and break points (pp. 11–13), a three-type degeneracy treatment (pp. 13–19), and a Maratos safeguard behind a user flag, Mflag (pp. 19–20).
  - Limits, stated concretely:
    - For Type iii degeneracy the authors know no obvious way to build reference sets. A constrained least-squares steepest-descent direction is used instead (p. 18).
    - Examples suggest the Maratos effect *could* occur with ψ as the merit function, but it has not been seen numerically (p. 19).
    - Convergence holds only under certain conditions (p. 21).
  - Stated future: general minimax problems, and constraints by what the authors call a rather straightforward extension (p. 22).

**Method links**:
- Method 6 ✅ (evidence): classical linear Chebyshev theory (Haar condition, alternant, Remez, Descloux's cadre) is carried into the nonlinear setting (pp. 3–7, 21). NLP devices are brought in as well: the null-space/range-space step and a Maratos correction in the style of Coleman–Conn and Fletcher, refs. [6], [11] (pp. 10, 19).
- Method 5 ⚠ (variant): the structure exploited is the structure of the *solution* (a levelled reference set with maximal deviation), not the composition of the objective (pp. 3, 8, 21). The code still uses exact gradients, so there is no black box here.
- Method 1 ⚠ (variant): theory, code and tests exist, but they are split across documents. Proofs live in the student's thesis, details in this report, and numbers in the companion report [7]/S108 (pp. 2, 22).
- new-pattern candidate: **Characterisation-driven algorithm design**. Restate optimality as a checkable structure, then design every direction to descend *and* move toward that structure (pp. 8, 10, 21–22). Also in S108.
- new-pattern candidate: **Self-audit of one's own earlier method** (cf. the s01 candidate *Self-audit note on one's own solver*). The motivation is a named failure mode of Conn's own 1978 descent method (p. 21).

**Transferable techniques**:
- For a max-type objective, use a three-part step acceptance test: sufficient decrease measured with the ε-active one-sided directional derivative, plus either a curvature test on a decreasing active piece or a gap-closing test against a non-decreasing piece. Prove that an acceptable interval exists and that steps are bounded below (pp. 11–12).
- Start the line search at the leftmost *break point*, where a non-working function first crosses the representative function along d. Then interpolate cubically on the active pieces and quadratically for the intersection, falling back to bisection (p. 13).
- To find the minimum-norm element of the convex hull of gradients (a steepest-descent direction at a degenerate point), solve the NNLS problem min ‖Ãλ − e_{n+1}‖ with λ ≥ 0, where Ãᵀ = [Aᵀ, e], and rescale θ* = λ*/eᵀλ* (Lemma 5.3, pp. 18–19).
- Guard against the Maratos effect by taking the horizontal step first and re-evaluating the functions. The levelling step is then computed at x + h, as v = −A(AᵀA)⁻¹Φ(x + h), and a user flag switches it on (pp. 19–20).

**Quotes**: none. The text file has no text layer, so no quote could be grep-verified.

### S108 · An efficient algorithm for nonlinear minimax problems (Cornell University, Dept. of Computer Science, TR 90-1104, March 1990; no DOI/arXiv)
**Role**: supplement · **Coauthors**: Yuying Li · **Position in trajectory**: the algorithm-and-numbers report of the Conn–Li cluster. S164 cites a Waterloo 1988 version as CS-88-41. It relies on the characterisation report CS-88-39 (ref. [13]) and on Li's thesis (ref. [23]) (pp. 4, 22–23). Conn was at Waterloo's Department of Combinatorics and Optimization, and Li at Cornell (p. 1). **Read**: all 24 pages, from page images (p. 2 is blank).

- **D1 Problem & entry**:
  - Problem: discrete nonlinear minimax min_x max_{i∈M} f_i(x), with the discrete Chebyshev problem as a special case using 2m functions f_{i+m} = −f_i. The f_i are C², and a local minimum is assumed to exist (p. 3).
  - Obstacle: ψ = max f_i is not differentiable at kinks, so gradient methods do not apply directly. Existing methods are SLP or NLP on an equivalent program (pp. 3–4).
  - Entry: the Remez experience for linear Chebyshev problems shows that demanding the solution's special features speeds solving (p. 4). The authors' own linear l∞ work [5] (Bartels–Conn–Li 1989) showed the importance of exploiting those properties computationally (p. 5). Ref. [13] generalised the characterisation to nonlinear minimax (p. 4). The paper's stated novelty is that the structure and characterisation of a solution are used explicitly (p. 4).
- **D2 Core idea & algorithm design**:
  - Model algorithm, six steps (p. 6): set up the working set; if a cadre exists, level or build a reference set; else descend and level; then line search and a termination test.
  - Working set (pp. 9–10):
    - W^k ⊆ Ŵ^{k−1} ∪ A(x^k, ε), with ε-active functions entered preferentially.
    - It grows by QR column additions while A^k stays *numerically* full rank.
    - A cadre is declared when ‖Zᵀ∇f_μ‖ ≤ τ_c^k, a *near* cadre.
  - Direction: the EQP (5.2) is solved approximately as d = h + v (5.3), dropping the ZᵀGv term as Coleman–Conn [10] suggest (p. 11).
    - h (null space of Aᵀ) is a descent direction that lowers all working functions equally to first order (Lemma 5.1, pp. 11–12).
    - v (range space of A) levels them.
    - If v is an ascent direction, only h is used (5.4) and the farthest-from-active function is removed (5.5). The authors report that an ascent v is rare in practice (p. 12).
  - Once a type-1 cadre is found, a signed levelling system (5.6) gives the vertical direction, and every index with a negative multiplier is dropped at once (5.7) (p. 13).
  - General minimax (ψ ≤ 0 case): an NLP-style multiplier-dropping rule is used (pp. 13–14).
  - Second order:
    - G^k switches among I, ∇²f_μ and Σλ_j∇²f_{ij}, depending on how long the working set has been unchanged (γ = 3, set arbitrarily) and how small the projected gradient is (6.1) (p. 14).
    - An extended BFGS update maintains the projected Hessian. It is initialised by finite differences and skipped when s_rᵀy_r ≤ 0 (p. 15).
  - Degeneracy is handled in three types:
    - A (only zero-sum cadres): use h.
    - B (unique sum-one cadre): level and halve τ_c (7.1).
    - C (several cadres): solve a simplex-constrained least-squares problem (7.2)–(7.3).
    See pp. 15–16. The full algorithm is on pp. 16–17.
  - Positioning claim: the method is not an active-set method. It identifies the correct active set quickly by recognising the structure of the optimum, keeping EQP's cheap iterations and IQP's fast active-set identification (p. 19, paraphrase).
- **D3 Assumptions & model**:
  - f_i ∈ C², and a local minimum exists (p. 3).
  - Numerical full rank of A^k, controlled through a tolerance on the smallest singular value (p. 9).
  - Z^TGZ is positive definite (p. 11).
  - Second-order sufficiency makes the projected Lagrangian Hessian positive definite near x* (p. 14).
  - The convergence assumptions themselves are not stated here. They are deferred to [23] (p. 22).
- **D4 Analysis (brief)**:
  - Proved here, for the cadre tests:
    - Lemma 3.2 (zero-sum cadre ⇔ rank deficiency) uses a *rank sandwich*. The multiplier relation gives rank(C) ≤ |C| − 1, full rank of A with Zᵀ∇f_{i0} ≠ 0 gives rank(C) ≥ |C| − 1, and Lemma 2.2 then certifies the cadre (pp. 7–8).
    - Lemma 3.3 (sum-one cadre ⇔ Zᵀ∇f_{i0} = 0) is an orthogonal-projection argument (pp. 8–9).
  - Proved here, for descent: Lemma 5.1 shows hᵀ∇f_μ = −(Zᵀ∇f_μ)ᵀB⁻¹(Zᵀ∇f_μ) < 0 iff Zᵀ∇f_μ ≠ 0. Since Aᵀh = 0, every working function changes by the same first-order amount (pp. 11–12).
  - Cited, not proved: the characterisation (Thm 2.4, from [13], pp. 4–5), Lemmas 2.5, 2.6 and 5.2 (from [13], pp. 5, 13), and global convergence with a superlinear rate (from [23], p. 22).
- **D5 Experiments**: 22 minimax/Chebyshev problems from the literature (n 2–20, m ≤ 51, published starting points) plus one real application (80 functions, 40 variables, 39 activities). The cost unit is function evaluations (Table 1), against Hald–Madsen, Conn 1979, Womersley–Fletcher and Charalambous, with rival numbers copied where available at comparable stopping tolerances. NM needs no more evaluations than CN, WF or CL wherever their numbers exist (one tie with WF, on Charalambous–Bandler 2) and wins the application (50 evaluations; Hald–Madsen failed). Against Hald–Madsen the picture is mixed on my reading of Table 1: HM stopped on round-off without a solution on 11 of 22 problems (footnote b), but where it finished it used fewer evaluations than NM on 6, e.g. Transmission 1 (21 vs 52) and El Attar (12 vs 25). The authors call the two comparable and break the tie with per-iteration cost: EQP needs two linear systems of size ≤ n, while Hald–Madsen solves an LP of size at least n × |M| (pp. 17–22).
- **D8 Contribution & limits**:
  - Contribution: algorithm and implementation, plus numerical results the authors call limited (pp. 19, 22).
  - Limits: the Maratos effect is possible with the current implementation but has not been observed. A fix (re-evaluate at x^k + h^k before the vertical step) is referred to [14] = S164 (p. 22).
  - Stated future: a constrained minimax extension, also in [14] (p. 22).
  - Claim wording is hedged: the method *appears* more efficient than [7], [12] and [33], and *still appears* preferable to Hald–Madsen (p. 22).
- **D6 lineage (note)**: one baseline is Conn's own 1979 second-order minimax method (CN, ref. [12]), which the new method beats wherever CN numbers exist (pp. 17, 21). Ref. [9] is the Charalambous–Conn 1978 SINUM method (p. 23).

**Method links**:
- Method 6 ✅ (evidence): the linear Chebyshev characterisation and Remez experience are carried into the nonlinear setting (pp. 4–5). NLP machinery is reused: QR null-space bases, projected quasi-Newton, and the Coleman–Conn simplification that drops ZᵀGv (pp. 9–11, 15). The design explicitly aims to combine the advantages of the EQP and IQP schools (p. 19).
- Method 2 ✅ (evidence): the test is two-tier, with 22 literature problems plus one real 80×40 application, and the cost unit is function evaluations (pp. 20–22). ⚠ Rivals are not rerun on shared code; their numbers are copied, where available, from the literature (p. 20). That is weaker than Workflow C.
- Method 1 ✅ (evidence, as a report cluster): characterisation report [13], thesis [23] for convergence, this report for algorithm and numbers, S164 for details (pp. 4, 22).
- Research Taste 6 ✅ (evidence): the claim is worded with *appears … preferable*, backed by a stated per-iteration cost argument, not by evaluation counts alone (pp. 18–19, 22).
- Heuristic 8 ✅ (analogue): the new method is benchmarked against, and replaces, Conn's own earlier minimax code (pp. 17, 21).
- new-pattern candidate: **Characterisation-driven algorithm design** (with S164). Every direction both descends and pushes toward the optimality certificate, a levelled reference set (pp. 5–6, 19).
- new-pattern candidate: **Degeneracy taxonomy with a remedy per type**. Classify degenerate points (A/B/C) by which cadres exist, and give each type its own direction or tolerance rule (pp. 15–16). This relates to the s01 candidate *Split by type, give each block its natural treatment*.

**Transferable techniques**:
- Split a step that must descend while equalising k functions into h = −ZB⁻¹Zᵀ∇f_μ, the null space of the difference-Jacobian A, which lowers all of them equally, and v = −A(AᵀA)⁻¹Φ, the range space, which makes them equal to first order. Keep v only if ∇f_μᵀv < 0 (pp. 5, 11–12).
- Detect a degenerate or optimal gradient configuration with the QR you already maintain: test ‖Zᵀ∇f_μ‖ ≤ τ_c, and halve τ_c whenever degeneracy is met (pp. 9, 16).
- Use the signs of the certificate's multipliers to drop several working constraints in one iteration, rather than one per iteration (5.7) (p. 13).
- Pick the Hessian model by a staleness rule: use first-order directions (G = I) until the working set has been unchanged for γ iterations, then switch to second-order information (p. 14). Skip a BFGS update that would lose positive definiteness (p. 15).
- When evaluation counts tie with a rival, report per-iteration linear-algebra cost (EQP vs LP or IQP subproblem size) as a second axis (pp. 18–19).
- Reuse NLP test problems for a minimax code through the transform min max{F, F − α_i g_i} with a known sufficiently large α_i (p. 20).

### S149 · An introduction to the standard data input format (SDIF) for nonlinear mathematical programming problems (Namur, Dept. of Mathematics, Report 91/8, 1991; file dated March 7, 1995; no DOI/arXiv)
**Role**: supplement · **Coauthors**: N. I. M. Gould, Ph. L. Toint · **Position in trajectory**: the LANCELOT period of the CGT trio. It is the user-level tutorial companion to the formal SIF proposal (Waterloo CS-89-61, ref. [5]), written after the 1988 bound-constrained trust-region paper and the 1991 augmented-Lagrangian paper (refs. [3], [6]) (pp. 4, 75). **Read**: the narrative parts: pp. 1–10, 14–15, 21–22, 24–26 (parts), 27, 30–31, 34–40 (pp. 36–37 in part), 50–51, 58, 60–61 (parts), 68 and 75–76. Not read: the worked SIF listings of §§2, 5, 6.1–6.8 and 7.1–7.3 (including p. 67), most of §3.3, the §8 syntax template (pp. 69–74) and the index (pp. 77–80).

- **D1 Problem & entry**:
  - Around 1986 the authors agreed that large nonlinear optimization problems were very hard to solve and that both a methodology and software were missing. This led to the bound-constrained trust-region method, then the general augmented-Lagrangian method, implemented with partial and group partial separability as LANCELOT (p. 4).
  - With version A of LANCELOT working, *stating* test problems became a formidable challenge in its own right. The structure that the algorithms need for performance was hard to write down (p. 4). The authors add, in parentheses, that the problems were needed to test the code (p. 4).
  - Entry: copy the success of MPS for LP and build a *standard input* for large nonlinear problems (p. 5).
- **D2 Core idea & design**:
  - MPS superset: the SIF syntax contains MPS as a subset, so existing LP test sets load without modification. The cost is a fixed-column format and old-fashioned keywords, which the authors accept as the lesser evil (p. 6).
  - Groups: nonlinear transformations g_i of linear forms, giving problem class (25)–(27) (pp. 21–22, 30).
  - Elements: nonlinear element functions whose *internal variables* are linear combinations of the elemental variables (a *range transformation*). Derivatives are given with respect to the low-dimensional internal variables (pp. 34–35, 38).
  - Problem class: min Σ g_i(a_iᵀx − b_i + Σ w_j f_j(x)), with the same kind of group constraints and bounds, i.e. group partial separability (36)–(38) (p. 38).
  - File chapters: SDIF (data), SGIF (group functions) and SEIF (element functions), with Fortran expressions for values, gradients and Hessians (pp. 22, 38–39). Gradient or Hessian availability is declared per element (p. 38).
  - Tools for size: indexing and loops, with the minimum-surface example at p = 7 giving 64 variables, 98 elements and 49 groups (pp. 39–40). Also variable scaling (pp. 50–51) and a free format (p. 58).
- **D3 Assumptions & model**: No theorems. The model is the problem class the format can express, restated at the end of each chapter: (25)–(27) on p. 30 and (36)–(38) on p. 38. Variables are assumed nonnegative and the start point 0 unless stated otherwise, inherited from MPS (pp. 9–10, 14).
- **D4 Analysis (brief)**: not applicable (no proofs). The technical content is the structural decomposition: groups, elements, and internal variables u = Wv (pp. 35, 38).
- **D5 Experiments**: none. There are only LANCELOT transcripts on toy problems such as SIMPLEST (pp. 9–10), the count of more than 500 problems specified in SIF (most solved by LANCELOT), and one anecdote: a user's energy-scenario problem with more than 1000 variables was specified, validated and solved in one hour, a case the authors expect to remain exceptional (p. 5).
- **D8 Contribution & limits**:
  - Contribution: software and infrastructure, namely a public input standard plus a tutorial.
  - Collection: the Moré–Garbow–Hillstrom, Toint, Moré and Buckley sets are already translated, Hock–Schittkowski and Schittkowski are in progress, and the stated intention is to put the files in the public domain (p. 68). The syntax template ships on the LANCELOT tape (p. 68).
  - Limits, candid and concrete:
    - The fixed format is rigid (pp. 7, 58).
    - MPS brings outdated keyword style (p. 6).
    - SIF is not a modelling language, compared with GAMS, AMPL and OMNI, and the authors call that paragraph a disclaimer (p. 6).
    - Blanks are significant in names, a hard-to-detect error source (p. 7).

**Method links**:
- Method 2 ✅ (evidence): the input format and the problem collection are presented as the way to test LANCELOT, with MPS compatibility for reuse, standard test sets translated, and the public domain as the aim (pp. 4–6, 68).
- Heuristic 7 ✅ (evidence): the solver (LANCELOT) is released together with its input format and syntax template (pp. 4, 68).
- Method 5 ✅ (evidence): structure is part of the *problem statement*, not something a solver has to discover. The authors say structural information is crucial for acceptable algorithm performance (p. 4) and that no modelling language of the day could express it (p. 6).
- Method 1 ✅ (evidence): the format exists because theory (refs. [3], [6]) and code (LANCELOT) needed a test stream (p. 4).
- new-pattern candidate: **Design the new standard as a superset of the incumbent**. Accept the incumbent's warts (fixed format, MPS keywords) so that its existing test sets and users carry over (p. 6).
- new-pattern candidate: **Tutorial that grows the expressible problem class**. Each chapter adds one construct and ends by stating, as a formula, the problem class now expressible (pp. 4, 30, 38–39).

**Transferable techniques**:
- When you propose a new input or benchmark format, make the dominant existing format a strict subset, so every existing instance becomes a test case on day one. State the price you pay for this explicitly (p. 6).
- Describe nonlinear structure with internal variables: when an element depends on elemental variables only through a few linear combinations (u = v − w), declare the range transformation and give derivatives with respect to u only (pp. 35, 38).
- Make derivative availability declarative and sparse: a gradient or Hessian counts as available once one entry is given, and unspecified entries are zero, which encodes sparsity (p. 38).
- In a manual or tutorial, close each chapter with the mathematical problem class the reader can now express (pp. 30, 38).

**Quotes**:
- "Both a proven methodology and suitable software were indeed badly needed." (p. 4)
- "none of these actually provides a way of specifying the nonlinear structure as does the SIF." (p. 6)
