# Paper cards · batch a2-01 (abstract / metadata level)

### S024 · Constrained optimization using a nondifferentiable penalty function (SIAM Journal on Numerical Analysis 1973, DOI 10.1137/0710063)
**Read**: abstract · **Role**: core (no full text) · **Coauthors**: none
- **D1 Problem & entry**:
  - The problem: a local constrained minimum with inequality and equality constraints, found through the exact penalty p₀ = μf − Σ min(0, φᵢ) + Σ |ψⱼ|, whose minimiser equals x₀ for small enough μ.
  - The entry point: p₀'s first derivatives are not everywhere defined, which had ruled out gradient-type methods (abstract).
- **D2 Key idea**: apply a modified form of gradient-type methods to a *perturbation* of p₀, and show how this solves the original constrained problem (abstract).
- **D8 Contribution**: theory plus "some numerical experience". The main theorem gives necessary and sufficient conditions for a minimum of the perturbed problem (abstract). Limitations: not stated in the abstract.

**Method links**:
- Method 6 ✅ (origin point): this is the 1973 penalty-function work that the Method 6 practice line of SKILL.md lists as mature machinery reused decades later. The abstract confirms what it is: gradient-type machinery made to work on a nondifferentiable exact penalty (abstract).
- Method 1 ⚠ variant: theorem and numerical experience appear in one paper, and no code is mentioned (abstract).
- new-pattern candidate: **Characterisation-driven algorithm design** (existing candidate, s2-02). The headline theorem is an optimality characterisation of the perturbed problem (abstract).

**Quotes**:
- "However, until recently, a serious drawback to this particular penalty function was that its first order derivatives are not everywhere defined." (abstract)
- "The main theorem consists of necessary and sufficient conditions for x to be a minimum of the perturbed problem." (abstract)

### S053 · Linear programming via a nondifferentiable penalty function (SIAM Journal on Numerical Analysis 1976, 13:145–154, DOI 10.1137/0713016)
**Read**: abstract · **Role**: supplement · **Coauthors**: none
- **D1 Problem & entry**: penalty methods had never been viable for LP, because they introduce nonlinearities (abstract).
- **D2 Key idea**:
  - The nondifferentiable penalty is piecewise linear on an LP, so the penalised problem stays linear in character.
  - The algorithm is presented in a numerically stable form closely related to Gill–Murray and to Conn's earlier work (abstract).
- **D8 Contribution**:
  - An LP algorithm whose computational efficiency is claimed comparable with, and in general better than, the standard form. How this was measured: not read.
  - It admits nonsimplex steps, which let it generalise readily to QP (abstract).

**Method links**:
- Method 6 ✅: the 1973 nonlinear penalty machinery is carried to LP (abstract).
- Method 5 ✅: the transplant works because of a structural fact: on LP the ℓ1-type penalty is piecewise linear (abstract).
- new-pattern candidate: **Recast as an instance of a solvable class** (see batch synthesis).

**Transferable technique**: pick the penalty whose form is closed over the problem class. On an LP, the ℓ1-type penalty keeps the subproblem piecewise linear, so the penalty method costs no more per step than the method it replaces (abstract).

**Quotes**:
- "Among other reasons, the penalty function approach has never been available for linear programming in a viable sense because of the inherent nonlinearities introduced." (abstract)
- "The method admits nonsimplex steps, and this feature enables it to be readily generalized to quadratic programming." (abstract)

### S014 · An efficient method to solve the minimax problem directly (SIAM Journal on Numerical Analysis 1978, DOI 10.1137/0715011)
**Read**: abstract · **Role**: core (no full text) · **Coauthors**: C. Charalambous
- **D1 Problem & entry**:
  - The entry is circuit and system designers' interest in minimax.
  - M_f(x) = maxᵢ fᵢ(x) has discontinuous first derivatives where two or more fᵢ tie at the max, so gradient methods do not apply directly.
  - Bandler–Charalambous treat minimax as the limit of least-pth. This paper is "direct" instead (abstract).
- **D2 Key idea**: two search directions.
  - The *horizontal* direction reduces M_f while keeping the near-active functions approximately equal.
  - The *vertical* direction reduces, by linearisation, the error within which those functions equal M_f.
  - A line search follows the horizontal step (abstract).
- **D8 Contribution**: an algorithm, with numerical results "to date" suggesting it is very efficient (abstract). Convergence theory: not stated in the abstract.

**Method links**:
- Method 4 ✅: the stated entry is demand from circuit and system designers (abstract), with an EE coauthor (metadata). This is the academic, pre-IBM form of the user's-door move.
- Method 5 ✅: the structure of the max function is exploited directly instead of smoothing it through least-pth (abstract).
- Method 1 ⚠ variant: algorithm plus numerical evidence; the abstract announces no theorem (abstract).
- new-pattern candidate: **Kink-manifold projection** (horizontal/vertical split). S164 (card s2-02) uses the same h + v construction in 1989.

**Transferable technique**: for an objective max of smooth fᵢ, split each iteration in two. A horizontal step decreases the max while holding the near-active fᵢ equal. A vertical step linearises the near-active fᵢ to close the gap between them. Line-search only along the horizontal step (abstract).

**Quotes**:
- "Over the past few years the circuit and system designers have shown great interest in minimax algorithms." (abstract)
- "We use two distinct search directions in the algorithm." (abstract)

### S015 · Minimization Techniques for Piecewise Differentiable Functions: The ℓ1 Solution to an Overdetermined Linear System (SIAM Journal on Numerical Analysis 1978, 15:224–241, DOI 10.1137/0715015)
**Read**: abstract · **Role**: core (no full text) · **Coauthors**: R. H. Bartels, J. W. Sinclair. The Scholar title drops "ℓ1"; it is restored from the abstract and the S202 reference list.
- **D1 Problem & entry**: the ℓ1 solution of an overdetermined m×n linear system, min Σ |aᵢᵀx − βᵢ|, which matters for robust fitting of linear models to data (abstract).
- **D2 Key idea**:
  - Minimise φ directly, in finitely many steps, with techniques borrowed from Conn's approach to piecewise differentiable functions.
  - At x, gradient discontinuities are handled through the projector onto the null space of A_Zᵀ, where A_Z holds the columns with zero residual.
  - A factorisation of A_Z is maintained and updated, for stability and efficiency (abstract).
- **D8 Contribution**: a finite algorithm that compares favourably with the best reported ℓ1 methods and extends easily to linear constraints (abstract). That extension appears in S042/S109 in 1980 (abstract, OpenAlex; metadata).

**Method links**:
- Method 6 ✅: Conn's NLP projection machinery is explicitly "borrowed" for ℓ1 data fitting (abstract).
- Method 1 ✅ (across papers): the 1978 algorithm leads to the 1980 constrained version with a Fortran implementation (S042) and to ACM Algorithm 563 (S109) (abstract; metadata).
- new-pattern candidates:
  - **Kink-manifold projection** (abstract).
  - **Recast as an instance of a solvable class**: the title frames ℓ1 fitting as piecewise-differentiable minimisation (title; abstract).

**Transferable technique**: at a kink, let the zero-residual (active) set define A_Z. Take descent directions from the projector onto the null space of A_Zᵀ, and update a factorisation of A_Z as the active set changes instead of refactorising (abstract).

**Quotes**:
- "Such solutions are of interest for the “robust” fitting of a linear model to data." (abstract)

### S051 · On Cline's Direct Method for Solving Overdetermined Linear Systems in the ℓ∞ Sense (SIAM Journal on Numerical Analysis 1978, 15:255–270, DOI 10.1137/0715017)
**Read**: abstract · **Role**: supplement · **Coauthors**: R. H. Bartels, C. Charalambous. The Scholar title drops the ℓ∞ symbol.
- **D1 Problem & entry**: minimise ‖Aᵀx − b‖∞ for an overdetermined system, building on Cline's direct algorithm (abstract).
- **D2 Key idea**:
  - A direct (descent) method that is finite.
  - Fast Givens transformations update the orthogonal factorisations, cutting the work per cycle without losing stability.
  - It needs no Haar condition and accepts linear equality and inequality constraints (abstract).
- **D8 Contribution**:
  - Comparisons are made with Stiefel's method and with Barrodale–Phillips.
  - The stated limitation: like other direct ℓ∞ methods, it often needs many more steps than indirect (ascent) methods on data-fitting problems (abstract).

**Method links**:
- Method 2 ✅: the baselines come from the competing (ascent/dual) school, and the abstract reports where the rivals win (abstract).
- Method 6 ✅: a numerical-linear-algebra device (fast Givens updating) is carried into a descent method (abstract).
- new-pattern candidate: **Self-audit of one's own earlier method** (existing, s01/s2-02). The step-count disadvantage conceded here is the question that S072 (1989) reopens and reverses (inferred from both abstracts).

**Transferable technique**: in the abstract itself, state the class of problems on which your method loses, and to whom. Here, direct methods need many more steps than ascent methods on data fitting (abstract).

**Quotes**:
- "This permits the work per cycle in the algorithm to be reduced without sacrificing numerical stability." (abstract)
- "Further, the method does not require the Haar condition, and it permits the easy accommodation of linear equality and inequality constraints." (abstract)

### S052 · Second-order conditions for an exact penalty function (Mathematical Programming 1980, DOI 10.1007/bf01581639)
**Read**: abstract · **Role**: supplement · **Coauthors**: T. F. Coleman
- **D1 Problem & entry**: characterise a local minimiser of an exact penalty function (abstract).
- **D2 Key idea**: first- and second-order conditions for the penalty function, whose form supports the claim that the exact penalty function and the NLP problem are closely related (abstract).
- **D8 Contribution**: theory, plus a negative result. There are points of the penalty function with no descent direction that are nevertheless not minimisers (abstract).

**Method links**:
- new-pattern candidates:
  - **Characterisation-driven algorithm design** (existing). Optimality conditions for the merit function come first. The Coleman–Conn algorithmic papers S018 (1982, card c2-01) and S030 (1982) follow; that ordering is by date and coauthor (inferred).

- Methods 1–6: no direct link (abstract).

**Quotes**:

- "In addition, we demonstrate that there exist arguments for the penalty function from which there are no descent directions even though these points are not minimizers." (abstract)

### S044 · A projected Newton method for ℓp norm location problems (Mathematical Programming 1987, 38:75–109, DOI 10.1007/bf02591853)
**Read**: abstract (the abstract of the Argonne report version, ANL/MCS-TM-56, Aug. 1985) · **Role**: supplement · **Coauthors**: P. H. Calamai
- **D1 Problem & entry**: continuous minisum multifacility location with the ℓp norm, 1 < p < ∞. The objective is not everywhere differentiable (abstract).
- **D2 Key idea**:
  - Characterise the minimum first. Then solve a finite sequence of linearly constrained subproblems, projecting the Newton direction onto the constraint manifold.
  - A specialised line search recognises first-derivative discontinuities and second-derivative unboundedness along the direction (abstract).
- **D8 Contribution**:

- Method 1 ✅: characterisation, algorithm, global and quadratic convergence, implementation and numbers, all in one paper (abstract).

- new-pattern candidates:
  - **Characterisation-driven algorithm design** (existing) (abstract).
  - **Kink-manifold projection** (abstract).

**Transferable technique**: in a line search on a function with kinks, precompute the points along the direction where a first derivative jumps, or where a second derivative blows up, as for ℓp distances at coincident points. Treat those points explicitly instead of trusting a smooth line search (abstract).

**Quotes**:

### S045 · An exact penalty function for semi-infinite programming (Mathematical Programming 1987, DOI 10.1007/bf02591681)
**Read**: abstract · **Role**: supplement · **Coauthors**: N. I. M. Gould
- **D1 Problem & entry**: semi-infinite programming, approached globally (abstract).
- **D2 Key idea**: generalise the ℓ1 exact penalty so that the penalties are *integrals* of constraint violations. The resulting penalty is exact and includes all violations (abstract).
- **D8 Contribution**: the integral merit function gives the algorithm a consistent model. Discretisation enters only through approximate quadrature, not as an a priori modelling step (abstract).

**Method links**:
- Method 6 ✅: the ℓ1 exact penalty line (S024, 1973) is transplanted to semi-infinite programming (abstract).

**Transferable technique**: for infinitely many constraints, penalise the integral of the violations over the index set. Let discretisation enter only through the quadrature rule used to evaluate that integral, so the algorithm's model stays the continuous problem and refining the quadrature does not change the problem being solved (abstract).

**Quotes**:
- "The merit function requires integrals for the penalties, which provides a consistent model for the algorithm." (abstract)
- "The discretization is a result of the approximate quadrature rather than an a priori aspect of the model." (abstract)

  That is 16 works with abstracts. The SKILL.md evidence line "penalty functions (1973, 1982)" can cite this range.
- **new-pattern candidate: Kink-manifold projection**. Treat the set where the nonsmooth pieces tie as a manifold. Take steps projected onto it (horizontal), plus a correction back toward it (vertical). Evidence: S097, S014, S015, S062, S044 and S043 (abstracts), plus S164 (s2-02 full card). This is a technique-level pattern, so it may fit Research Heuristics better than Core Methods.
- **new-pattern candidate: Recast as an instance of a solvable class**. Show that the target problem (LAV, LP, Chebyshev, the UFLP dual) is a special case of a class your algorithm already handles. Evidence: S116, S015 (title), S053, S043 (abstracts).
- **new-pattern candidate: Attribute the rival's advantage before competing**. Isolate the component that makes the rival win (S072: its starting point), explain it with theory, and graft it on. Evidence: S072 only, so it stays in the pool.
