### Patterns visible in the landscape (analysis)

1. **Paired outputs.** Theory papers come with numerical or software companions: CGT 1988 SINUM (convergence) + CGT 1988 Math. Comp. ("Testing a class of methods…"); CGT 1991 augmented Lagrangian theory → LANCELOT 1992 → "Numerical experiments with LANCELOT" 1996; Conn–Toint 1996 (algorithm + 20 test problems) → CST 1997 (convergence framework) → CST 1998 ("…in practice") → DFO code.
2. **Class-level theory.** Titles keep saying "a class of…", "general…": CGT 1988 ("a class of trust region algorithms"), CGT 1991 (analysis of "a class of augmented Lagrangian methods", abstract), CST 1997 ("a broad class of derivative-free trust-region methods… general framework"), CSV 2009 ("general derivative-free trust-region algorithms").
3. **The collaboration pattern changes over time but never stops.** Students at Waterloo (Coleman, Li, Calamai) → the CGT trio (more than 20 papers by the three alone, per the SIAM obituary) → IBM engineers (Visweswariah, Haring, Wächter) → the DFO trio (Scheinberg, Vicente, plus Toint and Zhang) → Montréal MADS group (Audet, Le Digabel) and application partners (Knudsen/Grossmann/Foss; Mongeau/Delahaye).
4. **Venues.** Core numerical-optimization journals (Math. Programming, SIAM J. Numer. Anal., SIAM J. Optim., IMA J. Numer. Anal., Math. Comp., ACM TOMS, OMS, COAP), plus the application communities' own venues (IEEE TCAD, DAC, AIAA MDO, Computers & Chemical Engineering, EJOR, CVPR).
5. **Tools carried from one setting to the next.** Penalty and augmented-Lagrangian ideas (1973, 1982, 1991) come back in 2018 as ℓ1-penalty and augmented-Lagrangian solvers for the quadratic subproblems inside MADS (Amaioua et al. abstract). The trust region (1988, 2000) becomes the frame for DFO (1996–2009).

### A. Recent progress in unconstrained nonlinear optimization without derivatives (Math. Programming 1997, DOI 10.1007/BF02614326) — with the companion Powell-festschrift paper (CUP 1997)

| Dimension | Content |
|---|---|
| Origin | **Speculation**: it came out of the IBM setting, where simulation-based objectives (circuits, engineering design) had no reliable derivatives. The abstract says it discusses "why [such methods] are in high demand by practitioners" (paraphrase of the snippet). The preceding Conn–Toint 1996 algorithm paper already targeted few evaluations and noise. |
| Why then | Powell's interpolation-based ideas existed, and Sauer & Xu (1995) had published a multivariate interpolation error bound, which the festschrift paper uses "extensively" (snippet). Conn had just finished a decade of trust-region convergence theory with Gould and Toint. |
| Key insight | Put the interpolation model inside a trust-region framework, and make the model's **geometric quality** an explicit, maintained property. Standard trust-region global convergence arguments then carry over. |
| Minimal evidence | Conn–Toint 1996: the algorithm was run on 20 test problems with and without noise (snippet of DOI 10.1007/978-1-4899-0289-4_3). |
| Abandoned paths | Unknown. |
| Reception | Became a standard reference for model-based DFO. The line leads to CSV 2008/2009 and to the 2009 book, which won the 2015 Lagrange Prize. |
| Methods shown | M1 (theory–code–test triad), M3 (certifiable model quality), M6 (transplanting trust-region machinery) |

### B. Global convergence of general derivative-free trust-region algorithms to first- and second-order critical points (SIAM J. Optim. 2009, DOI 10.1137/060673424)

| Dimension | Content |
|---|---|
| Origin | **Speculation**: the natural closing step after the two 2008 geometry papers. Once model quality is defined for interpolation, regression and underdetermined models, the convergence theorem can be stated once for all of them. |
| Why then | CSV 2008 (Math. Programming, received 2004) had supplied the geometry toolkit. The theory could be stated abstractly. |
| Key insight | Prove convergence for a *general* algorithm that only needs models of certified quality (the "fully linear / fully quadratic" style of condition; described in secondary sources as developed by CSV). Any model-building scheme that meets the condition then inherits the theorem. |
| Minimal evidence | The proofs themselves. It is a theory paper. |
| Abandoned paths | Unknown. |
| Reception | Widely cited. Later work relaxed the geometry requirement: Scheinberg & Toint 2010 "self-correcting geometry" (DOI via SIOPT 20(6):3512–3532) shows geometry steps cannot be removed entirely if convergence is to hold, but can be confined to criticality checks. |
| Methods shown | M3, M1 |

### C. LANCELOT: A Fortran Package for Large-Scale Nonlinear Optimization (Release A) (Springer 1992, DOI 10.1007/978-3-662-12211-2) — with "Numerical experiments with the LANCELOT package" (Math. Programming 1996, DOI 10.1007/BF02592099)

| Dimension | Content |
|---|---|
| Origin | **Speculation**: the CGT augmented-Lagrangian and bound-constrained trust-region theory (1988, 1991) needed a large-scale vehicle. The book explains "how one might present examples to the package" (snippet), which points to a user-facing input format. |
| Why then | Large-scale nonlinear problems were becoming routine. CUTE/SIF (1995) grew from the same effort: CUTE's problems are written in the standard input format used by LANCELOT. |
| Key insight | A convergent algorithm matters only if users can pose problems to it and it has been stress-tested on a large common collection. |
| Minimal evidence | 1996 paper: the algorithmic options of Release A, with "intensive numerical tests discussing the relative merits of the options" (snippet). |
| Abandoned paths | Unknown in detail. The 1996 paper compares options, so some options were presumably not made defaults (**speculation**). |
| Reception | 1994 Beale–Orchard-Hays Prize for Excellence in Computational Mathematical Programming (Conn, Gould, Toint; SIAM obituary). Later, inside IBM's own circuit tool, LANCELOT was replaced by the interior-point filter code IPOPT (MAM 2015 profile snippet). |
| Methods shown | M1, M2 |

### D. JiffyTune: circuit optimization using time-domain sensitivities (IEEE TCAD 1998, https://ieeexplore.ieee.org/document/736569/)

| Dimension | Content |
|---|---|
| Origin | Conn's own account (MAM 2015 profile, paraphrase from snippet): an IBM electrical-engineering colleague asked Conn for advice on minimax optimization. Later Conn was suggested as a relatively approachable mathematician and was invited to an internal workshop on circuit tuning. |
| Why then | Fast circuit simulation plus time-domain sensitivities made gradients available, and a general-purpose NLP package (LANCELOT) existed. |
| Key insight | Do not treat the circuit as a black box. Get sensitivities from the simulator and hand a well-posed nonlinear program (minimax, power, simultaneous transistor and wire tuning) to a general NLP solver. Also build "designer-friendly interfaces" and "recovery from nonworking circuits" (abstract snippet). |
| Minimal evidence | Unknown. |
| Abandoned paths | Unknown. |
| Reception | Led to EinsTuner (DAC 1999; FGCS 2005). Deployed "as a standard tool within IBM" for custom circuit design (MAM 2015). IBM Outstanding Technical Achievement Award with Haring and Visweswariah (SIAM obituary). |
| Methods shown | M4 (embed with the user), M5 (exploit structure / derivatives first) |

### E. Introduction to Derivative-Free Optimization (SIAM 2009, MPS-SIAM Series on Optimization, ISBN 9780898716689)

| Dimension | Content |
|---|---|
| Origin | **Speculation**: it consolidates the CST/CSV papers and pedagogically unifies direct search and model-based methods. |
| Key insight | Both frameworks, direct search (generalized pattern search, mesh-adaptive search, convergent Nelder–Mead variants) and model-based, can be taught "rigorously" in one book (publisher description snippet). |
| Reception | "First contemporary comprehensive treatment" (publisher description). 2015 Lagrange Prize in Continuous Optimization. The prize citation notes impact in "aerospace engineering, urban transport systems, adaptive meshing for partial differential equations, and groundwater remediation" (quote as shown in snippet; SIAM/MOS prize page). |
| Methods shown | M6 (cross-school synthesis), M3 |
