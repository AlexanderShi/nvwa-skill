# Proof playbook: Scheinberg-style complexity analysis templates

> Research date: 2026-09-27 (full-text pass). For a student who needs to prove convergence or complexity for a new stochastic, noisy or derivative-free algorithm in the style of Scheinberg's group.

## 0. The shared skeleton

Across the 2014–2026 papers the same moves appear. The 2022–2023 talk abstract "Overview of Adaptive Stochastic Optimization Methods" (MIT ORC; MICDE seminar video) summarises the programme: adaptive methods let the step-size parameter set the accuracy required of the stochastic approximations, so those requirements are adaptive and may be biased or even inconsistent. The step-size parameter is not bounded away from zero, which is the obstacle, and viewing the algorithm as a stochastic process with martingale behaviour gives expected complexity bounds that also hold with high probability (paraphrase of the abstract). The full texts state the same obstacle in their own words [card S057, p. 1] and the same key assumption: "The key to the analysis lies in the assumption that the accuracy improves in coordination with the perceived progress of the algorithm." [card S013, p. 11].

| Move | What you write down | Typical object |
|---|---|---|
| M1. Oracle contract | For iteration k, conditioned on the past (filtration F_{k−1}): the event I_k = "gradient/model accurate enough" has P(I_k = 1 \| F_{k−1}) ≥ p. The event J_k = "function estimates accurate enough" has its own probability. Accuracy is **relative to the step parameter**, e.g. ‖g_k − ∇f(x_k)‖ ≤ κ·α_k‖g_k‖ (step search) or a fully linear model on B(x_k, Δ_k) (trust region) [cards S012, pp. 8–9; S014, pp. 6, 14; S015, p. 5]. Write it in quantities the algorithm knows [cards S015, pp. 2, 7; S013, pp. 19–20] | indicator variables I_k, J_k; constants κ, p |
| M2. Deterministic lemma on good iterations | If I_k J_k = 1 and α_k (or Δ_k) ≤ ᾱ(ε), then the iteration is successful and gives decrease ≥ h(α_k, ε) (minus a noise term r if there is irreducible noise) [cards S014, pp. 15–16; S041, pp. 14–16; S093, pp. 5–8] | threshold ᾱ(ε) ∝ ε/L-type quantity |
| M3. Progress measure | Either a joint potential Φ_k = ν(f(x_k) − f_low) + (1 − ν)·(step term shaped like the per-step decrease: Δ_k², Δ_k³, α_k‖∇f(x_k)‖²), or a plain progress measure Z_k (f − f*, 1/(f − f*) or log((f − f*)/ε) by function class) [cards S013, p. 14; S047, pp. 4–6; D001, pp. 6, 19–20] | potential or progress measure |
| M4. Step parameter as a random walk | log_γ α_k moves up on successful good iterations and down otherwise. With p above the threshold, it drifts upward whenever α_k is below ᾱ, so it does not collapse. In counting proofs this appears as "small true steps ≤ small false steps" [cards S018, pp. 10–11; D001, p. 8; S057, pp. 9–10] | biased random walk |
| M5. Stopping time | T_ε = first k with ‖∇f(x_k)‖ ≤ ε (or a function-value gap). Bound E[T_ε] or P(T_ε > t) with one of the three templates below | E[T_ε] ≤ p/(2p − 1)·Φ₀/(Θh(Δ_ε)) + 1 [card S013, p. 9]; E[N_ε] ≤ 2p/(2p − 1)²·(2F_ε/h(C) + log_γ(C/α₀)) [card S014, p. 13]; P(T_ε ≤ t) ≥ 1 − exp(−(p − p̂)²t/(2p²)) − (damage tail) [cards D001, p. 10; S083, pp. 14–15] |

### 0.1 Three verified proof templates (corrected)

The first version of this file described only template (a). The full texts show three.

| Template | Guarantee | Skeleton | Canonical papers |
|---|---|---|---|
| **(a) Joint potential + renewal-reward** | expected | Potential Φ_k = νf + (1 − ν)Δ^q with q the order of the per-step decrease; case grid (‖∇f‖ ≥ ζδ_k or not) × (I_k, J_k); ν near 1 so every case but "both bad" is no worse than an unsuccessful step; the worst case offset by the best case of weight αβ; then E[Φ_{k+1} − Φ_k \| F] ≤ −Θh(Δ_k) and the renewal-reward theorem | [cards S013, pp. 5–10, 14–18; S015, pp. 8, 11; S047, pp. 4–8; S098, pp. 11–20] |
| **(b) Counting** | expected | Classify iterations as true/false × successful/unsuccessful × step above/below a threshold C; bound each class by the progress budget or by comparison with the true count; turn P ≥ p into counts with E[Σ W_k I_k] ≥ p·E[Σ W_k] for W_k fixed by the past; solve for E[N] | [cards S014, pp. 8–13; S026, pp. 8–13; S068, pp. 7–9; S088, pp. 17–18; S104, p. 21] |
| **(c) Deterministic counting + concentration** | high probability | Progress measure Z_k alone (no joint potential, no supermartingale); a deterministic lemma "not stopped and Σ I_k ≥ p̂t ⇒ enough good iterations"; Azuma–Hoeffding on Σ I_k − pt; a separate concentration bound on the accumulated noise damage; intersect and invert | [cards D001, pp. 7–13; S041, pp. 16–23; S083, pp. 11–17] |

**Which to use.** Random function estimates and an expected bound → (a). Exact f or bounded noise, expected bound → (b) (simpler; it is what the composite and Powell-style papers reuse). Any high-probability bound → (c). Before writing any of them, check whether an existing framework's hypotheses already cover your method (SKILL.md Method 7): the stochastic cubic-regularization paper, for instance, proves only realization-wise lemmas and then a theorem whose items are exactly the hypotheses of the high-probability framework, and imports its tail bound unchanged [card S093, p. 10].

**What the constants depend on:** L (gradient Lipschitz), Φ_0 (initial gap), γ (step-parameter factor), θ (Armijo / acceptance constant), κ's in the oracle contract, the probability gap (p/(2p − 1) in template (a) [card S013, p. 9]; 2p/(2p − 1)² in template (b) [card S014, p. 13]; 1/(p − ½ − noise term) in template (c) [card D001, p. 17]), and for DFO the dimension n through the model-error (poisedness / fully linear) constants [cards S088, pp. 9–11; S104, pp. 6–10]. Irreducible noise or bias (ε_f, ε_g) does **not** change the ε-order. It sets the smallest ε you can reach: ε ≥ O(√ε_f) + O(ε_g) for first-order trust region [card S041, p. 21]; ε of order √ε_f for noisy line search [card S026, p. 23]; ε_f^{2/3} for cubic regularization [card S093, p. 9]; √n·ε_f for model-based DFO [card S104, p. 16]. The oracle tutorial abstracts (2021–2024) describe this as bias affecting the neighbourhood of convergence rather than the rate (paraphrase of a search summary of the abstract). Constants are large: Θ carries a 1/1800 factor in the stochastic trust-region bound [card S013, p. 16], and plugging textbook values into STORM's conditions gives (1 − α)(1 − β) ≤ 1/440 [card S012, pp. 20–21].

## T0. Deterministic model-based DFO: the ancestor of every template

- **Canonical papers:** Conn, Scheinberg, Toint. On the convergence of derivative-free methods for unconstrained optimization (1997, Powell tribute volume) [card S008]; Conn, Scheinberg, Vicente. Global convergence of general derivative-free trust-region algorithms to first- and second-order critical points. *SIAM J. Optim.* (2009), https://doi.org/10.1137/060673424 [card S007]; Scheinberg, Toint. Self-correcting geometry…, *SIAM J. Optim.* 20 (2010), https://doi.org/10.1137/090748536 [card S030].
- **Setting:** smooth unconstrained, exact f, interpolation or regression models inside a trust region.
- **Assumption form (full text):** a model class that is fully linear (gradient error ≤ κ_eg Δ, value error ≤ κ_ef Δ² on the ball) plus a finite procedure that certifies or constructs such a model [cards S007, pp. 7–8; S143, p. 3]. The geometry operations are left abstract: "There is no need to specify exactly how this is done for the purpose of our theory" [card S008, p. 13].
- **Lemma pattern (full text):** (a) the criticality loop terminates; (b) the radius is bounded below away from criticality; (c) the key lemma \|ρ_k − 1\| ≤ model error / predicted decrease gives success once Δ_k ≤ c‖g_k‖; (d) the radius is not reduced before geometry is adequate [cards S008, pp. 14–19; S007, pp. 13–18]. The standard trust-region proof breaks in "three important aspects", and only those are re-proved [card S008, pp. 17–18].
- **Self-correction variant:** a failed step plus the interpolation error bound plus Σℓ_j = 1 forces a point with \|ℓ_j(x⁺)\| > Λ, so the rejected trial point repairs the set; dedicated geometry work is confined to the criticality step; finitely many swaps by a volume potential [card S030, pp. 6, 12–15].
- **Bound form:** liminf ‖∇f‖ = 0 (and lim, and second order in S007); no rate [cards S030, pp. 17–18; S007, p. 1].
- **Why it matters for you:** every later template keeps this skeleton, and the 2025–2026 complexity papers count its steps (T13). Knowing where the deterministic proof uses exact geometry tells you where a probabilistic model will break it.
- **Pitfalls:** the criticality step is where geometry cannot be dropped: a 2-D example converges to a non-stationary point without it, whatever the replacement rule [cards S030, pp. 8–11; S143, pp. 4–5].

## T1. Probabilistically fully linear models, exact function values

- **Canonical paper:** Bandeira, Scheinberg, Vicente. Convergence of trust-region methods based on probabilistic models. *SIAM J. Optim.* 24(3), 1238–1264 (2014). arXiv:1304.2808 [card S018, arXiv v1 read].
- **Setting:** smooth unconstrained, trust region, random first-order models (e.g., built from random samples), exact f.
- **Assumptions (full text):** models fully linear (κ_eg δ_k, κ_ef δ_k²) with probability ≥ 1/2 conditioned on the past models (Defs 3.1–3.2, pp. 6–7). The conditional form is chosen because independence from the past "is difficult to ensure" (p. 7). Model Hessians uniformly bounded "for convenience" (p. 7). One algorithmic change: a step succeeds (and the radius grows) only if ρ_k ≥ η₁ **and** ‖g_k‖ ≥ η₂δ_k (Alg. 3.1, p. 8).
- **Lemma pattern (full text, replaces the earlier inference):** (a) δ_k → 0 on *every* realization, because the radius only grows when ‖g_k‖ ≥ η₂δ_k and that forces a constant decrease of the exact f (Lemma 3.1, pp. 8–9); (b) W_k = Σ(2·1_{good} − 1) is a submartingale with bounded increments, so lim sup W_k = ∞ almost surely (Thm 4.1, pp. 9–10); (c) the log-radius rises by exactly 1 on good iterations below a level b and falls by at most 1 otherwise, so it dominates W_k, contradicting (a) unless liminf ‖∇f‖ = 0 (p. 11); (d) a reusable lemma: with signs of conditional probability ≥ 1/2, {Σ_good Z < ∞} ∩ {Σ_bad Z = ∞} is null (Lemma 4.1, p. 11) [card S018].
- **Bound form:** almost-sure first-order convergence (liminf and lim) and second-order liminf; no rate or complexity. The lim-type second-order result is left as Conjecture 5.1 because the second-order decrease bounds Σδ² rather than Σδ (pp. 20–21).
- **What the constants depend on:** fully linear constants κ_ef and κ_eg (poisedness of the sample set × Lipschitz constant), and trust-region update factors.
- **Pitfalls:** "with probability p" must hold **conditionally on the history**. Independence across iterations is not needed, but unconditional probabilities are not enough. With noisy f you are outside T1: go to T2.

## T2. Random models *and* random function estimates (STORM)

- **Canonical paper:** Chen, Menickelly, Scheinberg. Stochastic optimization using a trust-region method and random models. *Math. Program.* 169, 447–487 (2018). https://doi.org/10.1007/s10107-017-1141-8 (arXiv:1504.04231) [card S012, arXiv v2 read]. Origin in R. Chen's Lehigh PhD thesis "Stochastic Derivative-Free Optimization of Noisy Functions" (2015).
- **Assumptions (full text):** models α-probabilistically κ-fully linear (‖∇f − ∇m‖ ≤ κ_eg δ_k, \|f − m\| ≤ κ_ef δ_k²) conditioned on the past; estimates β-probabilistically ε_F-accurate (\|f̃ − f\| ≤ ε_F δ_k² at x_k and x_k + s_k) conditioned on a σ-algebra that already includes the current model; failures may be arbitrarily bad (pp. 3, 8–9). The estimate accuracy is "somewhat tighter" than the model accuracy (p. 9). Lipschitz f and ∇f on an enlarged region containing all iterates (Assumption 4.1, p. 10).
- **Lemma pattern (full text, corrected):** deterministic lemmas under good events (decrease ∝ ‖g_k‖δ_k; success when both are good and δ_k is small; good estimates make any accepted step decrease f by C₂δ_k²) (pp. 11–13). Then Φ_k = νf(X_k) + (1 − ν)Δ_k² with E[Φ_{k+1} − Φ_k \| F] ≤ −σΔ_k², by a split on ‖∇f‖ ≥ ζδ_k and the four (I_k, J_k) outcomes; ν close to 1; the "both bad" increase bounded by Taylor + Lipschitz and made rare (pp. 14–19). This gives ΣΔ_k² < ∞ a.s. The liminf step uses log_γ(δ_k/b) as a submartingale bounded below by a ±1 walk (pp. 21–22). The earlier guess that an extra expected-error condition controls bad estimates was **not** needed here: in first-order STORM an accepted bad step is bounded through ‖s_k‖ ≤ δ_k [card S013, p. 17].
- **Bound form:** almost-sure convergence. **Probability requirement (corrected):** αβ ≥ 1/2 suffices for the liminf step (p. 21), but the ΣΔ² theorem needs α and β close to 1 (Corollary 4.12); with textbook constants, (1 − α)(1 − β) ≤ 1/440 (Remark 4.13, pp. 20–21). Experiments succeed far below this (α ≈ 0.27, p. 31). The rate came later (T4).
- **Pitfalls:** accuracy ∝ Δ_k² means sample sizes grow like Δ_k^{-4} for sample-mean estimates with fixed variance (confirmed: O(σ_f²/Δ_k⁴) [card S013, pp. 19–20]; the implementation used about 1/δ_k "after testing various other rates" [card S012, pp. 28, 30]). The iteration analysis says nothing about total samples. That gap is closed in T9. Under biased computation failures, averaging repeated evaluations optimizes the wrong function (p. 26).

## T3. Counting argument for line search and cubic regularization with probabilistic models

- **Canonical paper:** Cartis, Scheinberg. Global convergence rate analysis of unconstrained optimization methods based on probabilistic models. *Math. Program.* 169, 337–375 (2018). https://doi.org/10.1007/s10107-017-1137-4 (arXiv:1505.06070) [card S014, arXiv v2 read].
- **Parallel analysis (not Scheinberg; not read in this corpus):** Gratton, Royer, Vicente, Zhang. Complexity and global rates of trust-region methods based on probabilistic models. *IMA J. Numer. Anal.* 38(3), 1579–1597 (2018). https://doi.org/10.1093/imanum/drx043. S014 calls it "The only other work that we are aware of" bounding the number of steps (p. 3); the high-probability idea of T7 is credited to it [card D001, p. 3].
- **Assumptions (full text):** a random model "sufficiently accurate" with probability ≥ p > 1/2 conditioned on the past, re-drawn every iteration; accuracy tied to the step the model produces: ‖G_k − ∇f(X_k)‖ ≤ κA_k‖G_k‖ for line search, gradient and Hessian errors ≤ κ‖S_k‖² along the step for ARC (Defs 2.1, 3.1, 4.1, pp. 6, 14, 22–23). Function values are exact (p. 2). Same γ for increase and decrease; with γ_inc ≠ γ_dec the 1/2 threshold would move (p. 13).
- **Lemma pattern (full text, replaces the inference):** reduce every algorithm to a process {A_k, F_k} with three checkable items: (i) a true, successful iteration raises F by h(α_k); (ii) if α_k ≤ C, a true iteration is successful; (iii) F is nondecreasing (Assumption 2.1, p. 8). Lemma 2.1: E[Σ W_k I_k] ≥ p·E[Σ W_k] for W_k fixed by the past (pp. 8–9). Counting over true/false × successful/unsuccessful × A_k above/below C (Lemmas 2.2–2.7, pp. 10–13); e.g. at most half of the iterations with A_k ≤ C are successful (Lemma 2.2). Theorem 2.1: E(N_ε) ≤ 2p/(2p − 1)²·(2F_ε/h(C) + log_γ(C/α₀)) (p. 13). Progress measure per class: f(x⁰) − f(x_k), 1/(f − f*), log(1/(f − f*)) (p. 7).
- **Bound form (full text):** O(ε^{-2}) nonconvex, O(ε^{-1}) convex, O(log 1/ε) strongly convex, O(ε^{-3/2}) for probabilistic ARC (Thms 3.1–3.3, 4.1, pp. 16–26); each followed by a remark that p = 1 recovers the deterministic method and p → 1/2 sends the bound to infinity. A high-probability tail is said to be "easy" but is not proved (p. 13).
- **Pitfalls:** exact function values are what make "successful ⇒ real decrease" true. Once f is noisy, the counting has to charge false successes (T6–T8). The constant 2p/(2p − 1)² differs from T4's p/(2p − 1); do not mix them.

## T4. Renewal-reward stopping-time analysis (expected complexity)

- **Canonical paper:** Blanchet, Cartis, Menickelly, Scheinberg. Convergence rate analysis of a stochastic trust-region method via supermartingales. *INFORMS J. Optim.* 1(2), 92–119 (2019). https://doi.org/10.1287/ijoo.2019.0016 (arXiv:1609.07428, titled "…via Submartingales") [card S013, arXiv v3 read, including the appendix].
- **Idea (full text):** analyse a *generic* process and bound the expected stopping time; "the first global complexity bound for a stochastic trust-region method" (p. 1). Reused by the stochastic line search (T5) and by ProxSTORM (T14).
- **Assumptions (full text, replaces the inference):** a process {Φ_k, Δ_k} with Φ_k ≥ 0 and a ±1 walk W_k with P(W = 1) ≥ p > 1/2; Δ_k bounded above; Δ_{k+1} ≥ min(Δ_k e^{λW_{k+1}}, Δ_ε) before stopping; E[Φ_{k+1} \| F_k] ≤ Φ_k − Θh(Δ_k) (Assumption 2.1, pp. 5–6).
- **Proof devices (full text):** a birth–death process with renewals when Δ_k ≥ Δ_ε, expected inter-arrival p/(2p − 1) (Lemma 2.1, pp. 6–7); R_k = Φ_{k∧T} + ΘΣ_{j<k∧T} h(Δ_j) is a nonnegative supermartingale (Lemma 2.2, pp. 7–8); Wald's identity for nonnegative increments, proved *without* assuming T < ∞, so convergence follows from the rate (pp. 8–9). For STORM: models (α; κ_eg δ_k, κ_ef δ_k²) and estimates (β; ε_F δ_k²), Φ_k = νf + (1 − ν)Δ_k² (p. 14), a case grid, and β chosen so a bad-estimate increase is at most half the unsuccessful-step decrease (pp. 16–18). Unbiasedness is not assumed (p. 4).
- **Bound form (verified):** E[T_ε] ≤ p/(2p − 1)·Φ₀/(Θh(Δ_ε)) + 1 (Thm 2.2, p. 9). For STORM, E[T_ε] = O(ε^{-2}/(2p − 1)) first order (Thm 3.3, p. 19), with Θ = (1/1800)·min{η₂β, κ_eg^{-1}} (p. 16); second order O(ε^{-3}/(2p − 1)) (Thm 4.2, p. 32). It also drops STORM's restrictive η₂ ≥ κ_ef (Remark 3.1, p. 12).
- **Why it matters for you:** once your algorithm is mapped to the generic process, the rate follows. Your work reduces to checking the assumptions for your oracle and step rule. The paper says its framework "can be applied beyond the algorithms discussed in this paper" (p. 33).
- **Pitfalls (corrected):** the mapping usually fails at "Φ decreases on good iterations" when function estimates can be wrong. In first order the bounded step saves you; in second order the bad case raises f by O(δ²) while a good step gains only O(δ³), so the paper adds a first-moment bound E\|F − f\| ≤ κ_F δ_k³ (Assumption 4.3, pp. 27–28). Bounded noise instead → T6.

## T5. Stochastic backtracking Armijo line search (expected complexity)

- **Canonical paper:** Paquette, Scheinberg. A stochastic line search method with expected complexity analysis. *SIAM J. Optim.* 30, 349–376 (2020). https://doi.org/10.1137/18M1216250. arXiv:1807.07994 v1 was titled "…with Convergence Rate Analysis" [card S015, arXiv v1 read; the published version, which may add experiments, was not read].
- **Assumptions (full text):** three parts: gradients κ_g-accurate relative to A_k‖G_k‖ with probability p_g; function estimates ε_f-accurate relative to A_k²‖G_k‖² with probability p_f; and a variance bound on the estimates (Defs 2.2–2.3, Assumption 2.4(iii), p. 5). Gradients need not be unbiased and may come from stochastic finite differences (p. 7).
- **Algorithm change (full text):** exactly one added control δ_k. A successful step is "reliable" if α_k‖g_k‖² ≥ δ_k², and δ_k then grows; otherwise it shrinks. δ_k sets the variance of the function estimates when ‖∇f‖ is unknown (pp. 3–4). The two failure modes it defeats are named: α collapsing to 0, and false acceptance raising f (p. 4).
- **Lemma pattern (full text, replaces the inference):** potential Φ_k = ν(f − f_min) + (1 − ν)A_k‖∇f(X_k)‖²/L² + (1 − ν)θΔ_k² (eq. 4.6, p. 11); the A_k‖∇f‖² term absorbs the growth of ‖∇f‖ after a successful step (Lemma 4.4, p. 10); three cases × three step types summarized in one table (Table 1, p. 11); bad estimates controlled by Hölder, E[1_{bad}\|F − f\|] ≤ (1 − p_f)^{1/2}·(second moment)^{1/2} (Lemma 2.5, p. 6). The general theorem is imported from T4 (Thm 3.3, p. 8).
- **Bound form (full text):** O(ε^{-2}) nonconvex with a p_g p_f/(2p_g p_f − 1) factor (Thm 4.11, p. 19), O(1/ε) convex (Thm 4.15, p. 21), O(log 1/ε) strongly convex (Thm 4.18, p. 22), via stopped transforms 1/(νε) − 1/Φ_{k∧T} and log Φ_{k∧T} with Jensen (pp. 19–22).
- **Pitfalls:** accuracy relative to ‖g_k‖ gets harder near stationarity. The theorem is an *iteration* bound, so do not present it as a sample bound. **Probability requirement (corrected):** not a 1/2-type threshold: p_g ≥ 16/17 and a p_f that depends on κ_g (Thm 4.7, p. 16; p. 7). With p_f = 1 the variance condition is unnecessary and p_g > 1/2 suffices (p. 6).

## T6. Bounded (adversarial) noise in function values

- **Canonical papers:** Berahas, Cao, Scheinberg. Global convergence rate analysis of a generic line search algorithm with noise. *SIAM J. Optim.* 31, 1489–1518 (2021). https://doi.org/10.1137/19M1291832 (arXiv:1910.04055) [card S026, arXiv v2 read]. Companion for the gradient estimator: Berahas, Cao, Choromanski, Scheinberg, *Found. Comput. Math.* 22 (2022), https://doi.org/10.1007/s10208-021-09513-z [card S006]; also arXiv:1905.13043 [card D003].
- **Assumptions (full text):** \|e\| ≤ ε_f, with ε_f known but not controllable (Assumption 1.3, p. 3). Two gradient conditions, each with probability 1 − δ conditioned on the past: the norm condition ‖g − ∇φ‖ ≤ θ‖∇φ‖ (θ < (1 − c₁)/(2 − c₁)), realizable by finite differences, interpolation and smoothing; and ‖g − ∇φ‖ ≤ max{ζε_g, κα_k‖g_k‖} for biased stochastic gradients (pp. 3, 6, 14–15). The convex case needs bounded iterates (Assumption 4.5, p. 17).
- **Lemma pattern (full text, replaces the inference):** the only algorithmic change is the +2ε_f slack in the Armijo test (eq. 2.1, p. 4), which lets accepted steps increase φ and breaks the monotonicity the earlier proof used (p. 2). The proof generalizes T3's counting with a four-part Assumption 3.3 (p. 7): true successful iterations gain ≥ h(α_k) − r(ε_f); small true iterations succeed; any successful iteration loses ≤ r(ε_f); r(ε_f)/h(ᾱ) ≤ γ < 1. Lemma 3.9: total gain minus total loss ≤ Z (p. 11); then a linear inequality in E[N] (p. 13). Every accepted step's true decrease is the model decrease minus 4ε_f (Lemmas 4.3–4.4, pp. 15–16).
- **Bound form (full text):** Theorem 3.13, for δ < 1/2 − √γ/2: E[N] ≤ 2(1 − δ)/((1 − 2δ)² − γ)·(2Z/h(ᾱ) + (1 − γ) log_τ(ᾱ/α₀)) (p. 13). O(1/ε²) nonconvex with ε of order √ε_f (Assumption 4.19, Thm 4.21, p. 23), O(1/ε) convex (p. 19), O(log 1/ε) strongly convex (p. 22). Each reduces to fixed-step gradient descent when δ = θ = ε_f = 0 (pp. 20, 22, 23). γ "is not an algorithmic parameter" (p. 8): it trades the failure probability against the neighbourhood.
- **Pitfalls:** a stopping test below the noise floor makes the method run forever or accept noise. The bound is on a hitting time: "there are no guarantees that the algorithm will remain in the near-optimal neighborhood, once it reaches it" (p. 29, as quoted on the card). Use the FoCM bounds (SKILL.md Method 5) to choose the estimator, N and σ (σ at the minimizer of an aσ + b/σ bound [card S006, pp. 6–7]).

## T7. High-probability tail bounds for adaptive step search

- **Canonical papers:** Jin, Scheinberg, Xie. High probability complexity bounds for line search based on stochastic oracles. *NeurIPS* 34, 9193–9203 (2021). Extended version: High probability complexity bounds for adaptive step search based on stochastic oracles. *SIAM J. Optim.* 34(3), 2411–2439 (2024). https://doi.org/10.1137/22M1512764 (arXiv:2106.06454) [card D001 = S043, arXiv v5 read]. Part of M. Xie's Cornell thesis.
- **Assumptions (full text):** SFO(ε_g, τ, κ, δ): ‖g − ∇φ‖ ≤ max{ε_g, min{τ, κα}‖g‖} with probability 1 − δ; SZO(ε_f, ν, b): E\|e\| ≤ ε_f plus a one-sided subexponential tail; only the noise of the difference f(x) − f(x⁺) needs to be subexponential (pp. 1, 5). The oracle constants are unknown to the algorithm; only ε′_f ≥ ε_f is an input (p. 4). A finite τ removes the step-size cap (p. 3).
- **Lemma pattern (full text, corrected):** axioms (i)–(v) on {I_k, Θ_k, Z_k, A_k}, each glossed in one line (p. 7). A step is large if A_k and A_{k+1} are ≥ ᾱ. Lemma 3.2: large successful steps ≥ large unsuccessful steps − d; Lemma 3.4: small true steps ≤ small false steps; key Lemma 3.5: T_ε > t and Σ I_k ≥ p̂t imply Σ U_kΘ_kI_k ≥ (p̂ − ½)t − d/2, a deterministic implication (pp. 8–9). Probability enters twice: Azuma–Hoeffding on Σ I_k − pt, P(Σ I_k ≤ p̂t) ≤ exp(−(p − p̂)²t/(2p²)) (Lemma 3.1, p. 7); and, for unbounded noise, a Bernstein-type bound on the *sum* of damages by induction on conditional MGFs (Prop. 1, pp. 11–12). The earlier inference "(iii) the number of large-step iterations is bounded by the Φ-budget" is right in spirit, but there is **no joint potential**: Z_k is ϕ − ϕ*, ln((ϕ − ϕ*)/ε) or 1/ε₀ − 1/(ϕ − ϕ*) by class (Table 1, p. 6).
- **Bound form (full text):** P(T_ε ≤ t) ≥ 1 − exp(−(p − p̂)²t/(2p²)) for bounded noise (Thm 3.6, p. 10) and with an extra damage term for subexponential noise (Thm 3.8, pp. 12–13). Nonconvex: with overwhelming probability, of order [1/(p − ½ − (4ε′_f + s)/(Cε²))]·(ϕ(x₀) − ϕ*)/(Cε²), for ε > max{ε_g/η, c·√(4ε′_f/(θ(p − ½)))}; O(L) dependence instead of O(L³) (pp. 15–17). Strongly convex/PL and convex versions (pp. 18–24). The deterministic complexity is essentially recovered at p = 1, ε′_f = 0 (Remark 2, p. 17).
- **Constants:** the probability threshold is p > 1/2 + r/h(ᾱ) (Assumption 3, p. 7); the bias levels set the reachable neighbourhood.
- **Oracle constructions (template, inference):** the paper gives sample-size conditions for mini-batch oracles and randomized finite differences (Props. 7–9, pp. 24–25; bias ε_g = 2(√n Lσ + √n ε_f/σ), minimised at σ = O(√ε_f)), but their proofs are deferred to the NeurIPS appendix, which was not read.
- **Pitfalls:** exponential tails need light-tailed function-estimate errors. Heavy tails give polynomial tails (T11). The experiments use a fixed mini-batch whose oracle properties are not checked (p. 26); keep the theory-vs-practice distinction explicit in your own paper.

## T8. Noisy trust region, first- and second-order, high probability

- **Canonical paper:** Cao, Berahas, Scheinberg. First- and second-order high probability complexity bounds for trust-region methods with noisy oracles. *Math. Program.* 207, 55–106 (2024). https://doi.org/10.1007/s10107-023-01999-5 (arXiv:2205.03667) [card S041, arXiv v3 read, including the appendices]. Part of L. Cao's Lehigh thesis (2021).
- **Assumptions (full text):** Oracle 0: bounded noise \|e\| ≤ ε_f, or a two-parameter subexponential tail (p. 4); Oracle 1: P(‖g − ∇φ‖ ≤ ε_g + κ_eg δ) ≥ p₁ ∈ [0.5, 1]; Oracle 2: the Hessian analogue with ε_H (pp. 4–5). Oracle constants belong to the oracle; δ is chosen by the algorithm from the radius (Remark 2.5, p. 5). Implementations derived for mini-batches (ε_g = σ/((1 − p₁)√N)) and finite differences / interpolation (pp. 8–9).
- **Algorithm changes (full text):** r ≥ 2ε_f (first order) or r ≥ 2ε_f + ε_g^{3/2} (second order) added to the numerator of ρ_k; the radius grows only if the step is accepted *and* ‖g_k‖ ≥ η₂δ_k (second order: max{‖g_k‖, −λ_min(H_k)} ≥ η₂δ_k); otherwise it shrinks, even on accepted steps (Algorithms 1–2, pp. 11–12). "Algorithms 1 and 2 are very similar to classical TR algorithms [11]. The major difference pertains to the fact that the step acceptance criterion is relaxed." (p. 11).
- **Lemma pattern (full text):** template (c). Deterministic lemmas on each sample path (pp. 14–16); indicators I_k, J_k, Θ_k, Θ′_k, Λ_k, Λ′_k; a **random** radius threshold Δ̄ = C₁ min_{k<T}‖∇φ(X_k)‖ − C₂ε_g, named as the new technique (pp. 3, 16); three counting lemmas and Azuma–Hoeffding on Σ I_k − p₁t (pp. 17–18); inversion through a monotone Q(·) (pp. 20–21). The subexponential case adds a second Azuma bound on Σ J_k and a Chernoff-plus-induction bound on accumulated errors (pp. 22–23).
- **Bound form (full text):** first order T = O(ε^{-2}) with an exponentially decaying tail, for ε ≥ O(√ε_f) + O(ε_g) (Thm 4.11, Remark 4.12, pp. 20–21); second order O(ε^{-3}) for ε ≥ O(ε_f^{1/3}) + O(√ε_g) + O(ε_H) (pp. 29–30, 37).
- **Pitfalls:** second-order results need the Hessian oracle's accuracy tied to Δ_k. The achievable (ε_g, ε_H) are bounded below by the noise. The theory does not explain behaviour with r < 2ε_f, which the authors report as an observed mismatch (p. 33).

## T9. From iteration complexity to oracle/sample complexity

- **Canonical paper:** Jin, Scheinberg, Xie. Sample complexity analysis for adaptive optimization algorithms with stochastic oracles. *Math. Program.* 209, 651–679 (2025). https://doi.org/10.1007/s10107-024-02078-z (arXiv:2303.06838) [card S057, arXiv v3 read]. The lower-bound lemma first appeared as an OPT 2021 workshop paper [card S137].
- **Problem it solves (full text):** "The step size parameters in these methods can increase and decrease based on the perceived progress, but unlike the deterministic case they are not bounded away from zero due to possible oracle failures, and bounds on the step size parameter have not been previously derived." (p. 1). Bounding total oracle cost is the same as lower-bounding α (p. 7).
- **Assumption (full text):** only the step-parameter process is abstracted: A_k ∈ {γA_{k−1}, min{α_max, γ^{-1}A_{k−1}}}, and P(increase \| F_k, k < T_ε, A_k ≤ ᾱ) ≥ p > 1/2 (Assumption 1, p. 7); oracle cost oc(α) non-increasing (Assumption 2, p. 12).
- **Lemma pattern (full text, replaces the inference):** write A_k = γ^{Y_k}ᾱ and couple Y with a one-sided reflected walk Z ≥ Y on every sample path (Lemma 1, pp. 9–10); bound the probability that the reflected walk reaches level ℓ within n steps from its explicit transition-matrix spectrum (Prop. 1, p. 10; proof credited to J. A. Fill, p. 20); choose ℓ ≍ log n (Theorem 1, pp. 8, 11). Then TOC(T_ε) ≤ n·oc(α*(n)), union-bounded with a high-probability iteration bound (Theorem 3, p. 13), or a layer-cake sum for the expectation (Theorem 2, p. 12).
- **Bound form (full text):** with probability ≥ 1 − n^{−ω} − c·n^{−(1+ω)}, either T_ε < n or min α_k ≥ ᾱγ·n^{−(1+ω) log_{1/2q}(1/γ)} (p. 8). STORM: gradient samples O(σ_g² ε^{-4} log(1/ε)), function samples of order σ_f² ε^{-6} (p. 16). SASS nonconvex: O(M_c/ε⁴ + M_v/ε²) gradient samples, the same as SGD (p. 19). Design consequence: choose γ as a function of p and n; less reliable oracles need a larger γ (Remarks 3–4, Cor. 1, p. 9).
- **Pitfalls:** this is the step that turns T2–T8 into statements practitioners care about. Referees will ask for it. Increase and decrease factors must be equal in this analysis; the unequal case is left open (p. 11). For STORM the high-probability version goes through Markov's inequality on E[T_ε], so its probability guarantee is weak (p. 16). The yardstick here is the stochastic lower bound and SGD, not the deterministic method (pp. 15–16).

## T10. Stochastic adaptive regularization with cubics (SARC)

- **Canonical paper:** Scheinberg, Xie. First- and second-order stochastic adaptive regularization with cubics: high probability iteration and sample complexity. arXiv:2308.13161; *INFORMS J. Optim.* (2026), https://doi.org/10.1287/ijoo.2025.0123 [card S093, arXiv v2 read, not the journal version]. The preliminary first-order version appeared at the Winter Simulation Conference 2023 [card S061].
- **Assumptions (full text):** SZO(ε_f, λ, a) sub-exponential with mean ≤ ε_f; SFO with probability ≥ 1 − δ₁; SSO (Hessian) with probability ≥ 1 − δ₂ (pp. 1–2). Accuracy inputs tied to the regularization parameter: μ/σ_k for the gradient, √(μ/σ_k) for the Hessian (Alg. 1, p. 4). The authors disclose that SFO/SSO must be implementable for arbitrarily small accuracy, which is stronger than in T7/T8 (p. 3). p = 1 − δ₁ − δ₂ − exp(−…) > 1/2 (Assumption 2, p. 9).
- **Lemma pattern (full text):** Method 7 in action. Realization-wise lemmas (model decrease ≥ σ‖s‖³/6; large σ gives success or a tiny step; step length bounded below by ‖∇ϕ(x⁺)‖; true + successful ⇒ decrease ∝ ε^{3/2} − 4ε′_f) (pp. 5–8), then Theorem 2 checks T7's axioms (i)–(v) item by item and Theorem 3 imports the tail bound (p. 10). One adjustment: progress is measured at the trial point, so the bound is on T_ε ≤ t + 1 (p. 10). Second order needs a new step-length lemma (Lemma 9, pp. 13–14).
- **Bound form (full text, replaces the inference):** O(ε^{-3/2}) with high probability and in expectation, matching deterministic ARC (pp. 3, 10–11); a smaller noise floor O(ε_f^{2/3}) against O(√ε_f) for step search and trust region (Remark 2, p. 9); sample complexity O(ε^{-3.5}) gradient, O(ε^{-2.5}) Hessian and O(ε^{-4.5}) function samples (Theorem 7, p. 18). The "outperforms other stochastic adaptive methods" claim is about complexity order; the paper has no numerical section (p. 3).
- **Pitfalls:** the relaxed inputs max{μ/σ_k, ‖s_k‖²} would suffice but depend on s_k, so they are left open (Remark 1, p. 5). Function-value sample complexity is worse than for methods that avoid function values (p. 19).

## T11. Unreliable inputs: corrupted gradients, heavy-tailed values

- **Canonical paper:** Scheinberg, Xie. Stochastic adaptive optimization with unreliable inputs: a unified framework for high-probability complexity analysis. arXiv:2511.19411 (2025) [card S083, read in full; no numerical section].
- **Assumptions (full text):** SZO(ε_f, q, ζ_q) bounds the mean error and a q-th centred moment (q ≥ 2); CZO: error ≤ ε_f with probability 1 − δ₀ and ≤ ε_f + ε_c always; SFO: ‖g − ∇ϕ‖ ≤ r(α) with probability ≥ 1 − δ₁, arbitrary otherwise (pp. 2–4). "Highly unreliable" means p < 1/2 (Def. 2, p. 10). Optional: moments of function-value *differences* (eqs. (6)–(7), p. 3). Two algorithm-level assumptions: small true iterations succeed; large successful iterations decrease ϕ by h(ε) minus noise (p. 12).
- **Lemma pattern (full text):** template (c) with a plain progress measure Z_k = ϕ(X_k) − ϕ* and no joint potential (Def. 6, p. 11). Among small iterations each successful one is matched by ≥ ⌊m⌋ unsuccessful ones, m = −ln γ_inc/ln γ_dec (Lemma 2, pp. 12–13); large unsuccessful ≤ ⌈m⌉ × large successful + log term (Lemma 3, p. 13); large successful ≤ (Z₀ + noise)/h(ε) (Prop. 2, pp. 13–14); Theorem 1 intersects {Σ I_k ≥ p̂t} (Azuma–Hoeffding) with {accumulated noise ≤ t(2ε_f + μ + s)} (pp. 14–15). The noise event's tail changes with the oracle: Fuk–Nagaev (polynomial), Chebyshev (q = 2), Bernstein (sub-exponential), Hoeffding (CZO) (pp. 15–17).
- **Bound form (full text):** the threshold is p > 1/(m + 1), i.e. p·ln γ_inc + (1 − p)·ln γ_dec > 0, so a large increase factor tolerates p < 1/2 (pp. 15, 22); E[T_ε] = O(ε^{-2}) for trust region and line search (pp. 20, 22); tails exponential or polynomial by oracle; JSX24 recovered as a special case (p. 22).
- **Lesson:** the *tail shape* of your complexity bound is inherited from the tail of the function-value oracle. State it explicitly. p is usually unknown and must be replaced by a conservative lower bound (pp. 15, 22).

## T12. Composite convex problems with adaptive step search

- **Canonical paper:** Nguyen, Scheinberg, Tran. Stochastic ISTA/FISTA adaptive step search algorithms for convex composite optimization. *J. Optim. Theory Appl.* 205, article 10 (2025). https://doi.org/10.1007/s10957-025-02621-8 (arXiv:2402.15646) [card S068, arXiv v2 read].
- **Assumptions (full text):** P(‖G − ∇f‖ ≤ κ‖D_α(y)‖) ≥ p > 1/2 with D_α the gradient mapping, κ ≤ 1/3, no unbiasedness (p. 4); exact function values and exact prox, admitted as strong (p. 2); plus an iteration-indexed variance decay E‖∇f − G‖² ≤ 1/(α_k² k^{2+β}) (ISTA) or 1/(α_k² t_k² k^{2+β}) (FISTA) (pp. 11, 20).
- **Obstacle and repair (full text):** FISTA's step parameter may only decrease, which is fatal stochastically; the repair is the authors' own deterministic full-backtracking FISTA-BKTR with θ_k bookkeeping, made stochastic, with the gradient re-estimated on every attempt (pp. 2, 5, 14–15).
- **Lemma pattern (full text):** template (b) for the generic part, E(N_ε − 1) ≤ 2p/(2p − 1)²·(2E(N_G) + log_γ(ᾱ/α₁)), reusing the Cartis–Scheinberg counting lemmas (Theorem 1, pp. 6–9); then an algorithm-specific bound on the number of good iterations by Schmidt et al.'s error-accumulation argument, a FISTA potential that is constant on unsuccessful steps, and Wald's identity at the hitting time (pp. 9–20).
- **Bound form (full text):** E(N_ε) = O(1/ε) for ISTA and O(1/√ε) for FISTA, the deterministic orders (pp. 13, 21).
- **Use:** the template for adding a prox term with exact f. **Pitfalls:** the variance decay means sample sizes growing like O(k²), and "whether we attain an optimal complexity with our analysis remains unknown" (p. 13); only expected bounds; stochastic function estimates, high probability and the strongly convex case are future work (pp. 2, 13, 22). For nonconvex f + convex φ with random estimates, see T14.

## T13. Worst-case complexity of model-based (Powell-style) DFO, including random subspaces and noise

- **Canonical papers:** Chaudhry, Scheinberg. On complexity of model-based derivative-free methods. arXiv:2510.14935 (2025; listed on the co-author's homepage as ICM 2026 proceedings) [card S088, read in full]. Chaudhry, Scheinberg, Sun. Powell-style model-based derivative-free optimization with complexity guarantees. arXiv:2609.09441 (2026) [card S104, arXiv v1 read].
- **Parallel work (not Scheinberg; not read in this corpus):** Cartis, Roberts. A note on the complexity of random subspace model-based methods for derivative-free optimization. arXiv:2608.17307 (2026).
- **Claims (abstract):** complexity bounds are derived systematically for classical model-based trust-region methods and modern variants. They are shown, for the first time, to have the same worst-case complexity as any other known DFO method. Powell's geometry handling is fully incorporated. Random subspaces give what the authors believe to be nearly tight complexity, and the analysis extends to noisy evaluations.
- **Lemma pattern (full text, replaces the inference):**
  - *Deterministic counting* (template (b) without probability): a small radius with a fully linear model forces success; success decreases ϕ by ≥ C₂Δ² (minus 2ε_f with noise); the radius stays ≥ γC₁ε; successful iterations ≤ (f₀ − f*)/(C₂(γC₁ε)²); unsuccessful ≤ successful + log term [cards S088, pp. 3–4; S104, pp. 5–6]. The criticality step is replaced by the acceptance test ‖g_k‖ ≥ η₂Δ_k from T1 [cards S088, pp. 2–3; S104, p. 4].
  - *Model error with explicit n*: ‖∇ϕ − g‖ ≤ ½√n·LΔ·√(n(Λ² − 1) + 2) via tr(A) + tr(A^{-1}) ≤ n(Λ² + 1), so κ_eg = O(√n) with Λ = 1 + O(1/n) [card S088, pp. 9–11]; a Sherman–Morrison family shows the Λ-dependence is tight (Thm 4.6, pp. 11–12). The noisy version adds √n·2ε_fΛ/Δ [cards S088, pp. 10–11; S104, pp. 8–10].
  - *Counting geometry steps*: a growing orthogonal set (≤ 3n calls between non-correcting iterations) [card S088, p. 8]; a volume ratio with Hadamard's inequality (O(p log p)) [card S088, pp. 12–13]; −log\|det Y\| contracting by (1 − 1/n) per swap, plus an induction showing Y is 14ⁿ-poised after 2n steps [card S104, pp. 13–15].
  - *Random subspaces*: "well aligned" plays the role of I_k with probability θ ≥ 243/443 > 1/2 (Beta law + Paley–Zygmund) [card S088, pp. 16–17]; expected complexity by the Cartis–Scheinberg counting, E[K_ε] ≤ 2θ/(2θ − 1)² × the deterministic count [card S088, pp. 17–18]; with noise, a relaxed ratio +2ε_f and an explicit floor Δ_min = Θ(√ε_f), because a poor subspace removes the automatic radius lower bound [card S104, pp. 17–22].
- **Bound form (full text):** O(n²ε^{-2}) evaluations for the geometry-correcting method with Λ = 1 + O(1/n), the same as finite differences [card S088, p. 11]; O(n^{3/2} log n·ε^{-2}) with η₂ = √n and point reuse [card S104, p. 16]; subspaces O(nq/ε²) (finite differences) and O(nq log q/ε²) (geometry correcting) with noise [card S104, pp. 21–22]; reachable ε ≥ Ω(√n·ε_f) [card S104, p. 16].
- **Pitfalls:** report the dimension dependence explicitly. Count geometry steps. "Nearly tight" is a belief stated in the abstract, not a proven lower bound (see open-problems.md). Subspace results are expected bounds only; a high-probability version is open [cards S088, p. 18; S104, p. 21]. The theory covers linear Lagrange polynomials; the best practical variant (quadratic self-correction) is not covered [card S104, pp. 24–25].

## T14. Nonconvex f plus convex nonsmooth φ with random estimates (ProxSTORM)

- **Canonical paper:** Baraldi, Javeed, Kouri, Scheinberg. ProxSTORM — a stochastic trust-region algorithm for nonsmooth optimization. arXiv:2510.03187 (2025) [card S098, arXiv v2 read; same text as the 2024 Sandia report, card S107]. (Earlier versions of this skill called it a third-party paper; Scheinberg is an author.)
- **Assumptions (full text):** ϕ proper, closed, convex with an exactly computable prox; f L-smooth on dom ϕ, possibly nonconvex (pp. 1–2); P(I_k \| F_{k−1}) ≥ α with I_k = {‖∇M_k − ∇f‖ ≤ κ_grad Δ_k}; P(J_k \| F_{k−1/2}) ≥ β with J_k = {\|A_k − C_k\| ≤ ηP_k}, a contract on the *reduction difference* scaled by the predicted reduction, with a half-step filtration (pp. 5–7); an expected-increase bound on successful steps with inaccurate reductions, implied by E\|C_k − A_k\| ≤ c₃Δ² (Assumption 5, Prop. 2, p. 8); α, β close enough to 1 (pp. 15, 20).
- **Lemma pattern (full text):** template (a). - **Pitfalls:** only expected complexity; the high-probability bound and the total sample complexity are delegated to T9-type results (pp. 9, 23). α and β are hard to determine numerically (Remark 12, p. 16). Verify-until-pass inexactness loops amplify the chance of an erroneous exit under probabilistic conditions (p. 28).

## T15. Comparison oracles: optimization without an objective function

- **Canonical paper:** Scheinberg, Xiong. Function-free optimization via comparison oracles. arXiv:2604.26867 (2026) [card S087, arXiv v2 read; no numerical section].
- **Setting (full text):** only a preference relation is available; guarantees must be stated in quantities invariant under monotone transformations: the level-set gap Δ_LS(x) and the regularity radius r_x replace f − f* and ‖∇f‖ (pp. 2–4, 9–12). If an L-smooth f realises the relation, r_x ≥ ‖∇f(x)‖/L (Lemma 2.10, p. 11).
- **Lemma pattern (full text):** a halfspace certificate from one comparison (Lemma 3.1, p. 13); planar bisection along d − 1 tangential directions with the normal read off the orthogonal complement (Algs 1–2, pp. 14–16); error = geometry bias + bisection error, O(d log(d/ε)) comparisons (Thm 3.5, Cor. 3.6, pp. 16–17); an adaptive radius with a log(1/δ) tail via a random rotation of the dyadic grid (pp. 18–23); matching lower bounds for direction estimation (pp. 24–26) and for span methods (pp. 41–43); the outer methods are classical (Shor's normalized subgradient; KT coin betting) with a two-case guarantee (pp. 28–40).
- **Why it matters for you:** the yardstick is not deterministic parity but a matching minimax lower bound at each layer (estimator and outer method).
- **Pitfalls:** noiseless oracle; global guarantees need convex sublevel sets; the minimax number of comparisons for the whole problem is open (p. 44).

## Common pitfalls checklist (use before showing a proof to your supervisor)

1. Is every probability **conditional on the past** (F_{k−1}, or a half-step filtration when the model and the estimates are drawn separately), and is the required p stated with **the threshold your template actually needs** (1/2 for BSV-type liminf arguments; α, β close to 1 for STORM's ΣΔ² theorem; 16/17 for the stochastic line search; 1/2 + r/h(ᾱ) for high-probability step search; 1/(m + 1) with asymmetric factors)?
2. Is the accuracy requirement tied to the **step parameter** (α_k, Δ_k), not to the target ε? A fixed-accuracy analysis is a different, weaker result. Is every sample-size rule written in quantities the algorithm knows?
3. Do bad function estimates have a controlled effect (bounded step in first-order trust region; a first-moment bound in second order; a variance condition in line search; a tail assumption for high probability)? Otherwise one catastrophic estimate breaks the argument. Check for an order mismatch between the worst damage and the guaranteed gain.
4. Did you separate **iteration**, **oracle/sample** and (for DFO) **function-evaluation** complexity? Which one does your theorem bound?
5. Did you state the **neighbourhood** set by irreducible noise or bias, and a stopping rule that respects it? Did you say that a hitting-time bound does not keep the iterates in the neighbourhood afterwards?
6. Does the ε-order match the deterministic counterpart (or, for sample complexity, the stochastic lower bound)? If not, is the gap intrinsic (lower bound?) or a proof artefact?
7. Is the result almost sure, expected, or high probability? Did you try to upgrade to a tail bound?
8. Did you reuse a canonical template (T4 renewal-reward; T3 counting; T7/T11 high-probability framework) instead of re-deriving it? If a framework's hypotheses fit, did you write the checklist theorem with one gloss per hypothesis?
9. Is your stopping time really a stopping time with respect to your filtration? A T_ε defined through x_{k+1} is not, which blocked the first attempt at stochastic cubic regularization [card S047, p. 12]; the fix in T10 was to shift the bound by one iteration [card S093, p. 10].
10. After each theorem, set the noise and probability parameters to zero: does the deterministic bound come back [card S026, pp. 13, 20, 22–23]?
